# Aquarius 隐私政策

版本 1 · 生效日期 2026 年 11 月 3 日

本政策说明 Aquarius（以下称「本程序」）如何处理你的信息。**结论先说：本程序不收集你的个人信息。你的会话、附件、记忆与密钥都保存在本机；只有你主动发起、并且发往你自己配置的服务商时，相关内容才会离开这台机器。**

## 1. 谁在处理

本程序由 Aquarius 的作者（自然人，GitHub：@Tonyjh07）发布，联系邮箱 yjh07@qq.com，项目主页 https://github.com/Tonyjh07/Aquarius 。本政策所称个人信息处理者即该自然人，联系方式见第 13 节。

本程序是单机软件，不设账号，不设服务端。我们不运营任何接收你会话内容的服务器。

## 2. 结论

2.1 我们不收集、不上传、不转售你的会话内容、附件、记忆、密钥或使用记录。
2.2 本程序没有使用统计、崩溃上报、更新检查与广告组件。
2.3 数据默认只存在于你的机器上，处置权也在你手上。

## 3. 本机保存的内容

3.1 下列内容都保存在你的机器上，位置在数据根 `~/.aquarius/` 之下；表格里的 `<档名>` 是配置档的名字，默认档叫 `default`。

| 内容 | 默认位置（数据根 `~/.aquarius/` 之下） | 说明 |
|---|---|---|
| 会话 | `profiles/<档名>/conversations/<编号>.json` | 消息、分支、工具调用与结果；同目录保留最近 3 代备份（`.bak` / `.bak.1` / `.bak.2`） |
| 附件 | `profiles/<档名>/attachments/` | 图片与文档原字节，按内容寻址 |
| 记忆 | `profiles/<档名>/memories.md`、`profiles/<档名>/conversations/<编号>.memory.md` | 纯 markdown，你可以直接编辑 |
| 配置 | `profiles/<档名>/config.json` | 服务地址、模型名、密钥引用 |
| 密钥 | `profiles/<档名>/secrets.bin` | 本机加密；换一台机器解不开 |
| 审计日志 | `profiles/<档名>/audit.log` | 工具调用记录 |
| 任务日志 | `profiles/<档名>/jobs/` | 后台任务的输出 |
| 运行日志 | `profiles/<档名>/logs/aquarius-YYYY-MM-DD.log` | 启动、装配与模型链路的告警；按天切分，保留最近 7 天 |
| 界面状态 | `profiles/<档名>/gui_pos.json` | 窗口上次停留的位置 |

3.2 数据位置可用启动参数 `-data` 更改；`-profile` 可隔离多套配置，互不影响。数据根上的 `config.json` 只记当前档名，档与档之间互不影响。

## 4. 离开本机的内容

4.1 只有下面五类，且都由你的动作触发——发消息、录音、朗读、使用工具、安装扩展。

| 内容 | 接收方 | 触发动作 |
|---|---|---|
| 消息、附件的文字或图片、截屏、待朗读文本、录音音频 | 你在「模型服务」「语音」中配置的服务商，以及你启用的降级备用服务商 | 发送消息、朗读、录音 |
| 录音音频 | 你选择的云端识别服务商 | 录音（识别方式选「本地 whisper」时音频不出本机） |
| 搜索词、目标网页地址 | 你配置的搜索或抓取服务商 | 使用联网搜索、网页抓取 |
| 技能包的下载请求 | 你提供的链接（例如 GitHub） | 安装或更新技能 |
| 工具请求与返回结果 | 你配置的 MCP server（本机进程，或你填写的网络端点） | 模型调用该工具 |

4.2 我们不中转、不落库、不留存副本。上述传输由你的机器直接发往相应服务商。
4.3 默认配置里预置了 DeepSeek 一家的接口地址，只为省去你手填；地址与模型都可随时更改，也可以改为完全本机的服务。
4.4 若你配置的服务商位于你所在的国家或地区之外，上述内容将传输至境外。这是你的选择，你需要自行判断是否满足你所在地区关于个人信息出境的要求；我们不参与该传输，也无法代为办理相关手续。我们无法预先告知具体的境外接收方，因为向哪家服务商发送内容完全由你决定；请以该服务商的隐私政策为准。

## 5. 我们不做的处理

5.1 不建立用户画像，不做定向推送，不进行自动化决策。
5.2 不向第三方提供、出售或公开你的信息。
5.3 不读取你的会话用于训练或改进模型。
5.4 不做跨设备同步，不做云端备份。

## 6. 第三方服务与你

6.1 你是与上述服务商直接建立关系的一方。它们的隐私政策与条款适用于它们对你信息的处理；我们不是它们的代理人、转售方或共同处理者。
6.2 我们无法控制这些服务商如何处理你的内容，也无法代你行使你在它们那里的权利。相关请求请向对应服务商提出。

## 7. 敏感个人信息

7.1 截屏、录音与文件内容可能包含敏感个人信息，例如生物识别、医疗健康、金融账户、行踪轨迹。本程序的默认设置是：截屏与高风险工具逐次确认；录音可选用本地识别，此时音频不出本机。
7.2 请不要向模型提交你无权处理的他人敏感个人信息。若你这样做，你应自行取得同意并承担相应责任。
7.3 密钥保存在本机加密的密钥库中，不写入日志，也不进入会话文件。

## 8. 未成年人

本程序不面向不满 14 周岁的未成年人提供，我们不会主动收集未成年人的个人信息。若你是未成年人的监护人，发现其正在使用本程序，请引导其停止使用，或在你指导下使用。

## 9. 你的权利与行使方式

9.1 你可以按下列方式行使你的权利：

| 权利 | 怎么行使 |
|---|---|
| 查阅、复制 | 会话是 JSON，记忆是 markdown，附件是原字节：直接打开数据目录即可；也可用导出功能打包 |
| 更正、补充 | 直接编辑文件，或修订某条消息生成新分支 |
| 删除 | 删除对应文件；或删除整个数据目录 |
| 撤回同意 | 关闭相应功能（语音、截屏、联网搜索、外部代理），或卸载并删除数据目录 |
| 解释说明 | 发邮件询问 |

9.2 **因为数据不在我们的服务器上，我们无法代为查阅、更正或删除。** 这不是推诿，而是本地优先设计的必然结果：这些操作只能由你在自己的机器上完成。若操作中遇到困难，可以联系我们，我们会尽力说明方法。

## 10. 安全措施

10.1 密钥库本机加密；密钥不写入日志，也不进入会话文件；审计日志记录工具调用；四档权限矩阵与逐次确认；附件按内容寻址存储；未引用的附件在启动时清理。
10.2 请注意：本机安全最终取决于你的设备与账户安全。共享电脑、弱口令、恶意软件都可能使上述措施失效。

## 11. 保存期限

由你决定。本程序不设自动过期，也不自动清理会话与记忆。卸载并删除数据目录后，相关数据即被删除。

## 12. 变更

12.1 本政策可能随功能调整而修订。修订版随新版本程序发布，并在首次运行时提示你阅读。
12.2 处理目的、方式或信息种类发生重大变化时，我们会单独提示并重新征求你的同意。
12.3 每份政策标注版本号与生效日期；版本变化时，首次运行会要求你重新阅读并确认。
