## English

> Note: this file is generated by the program and rewritten on start-up when the version changes.
> Keep your own notes in a separate file. The repository is
> <https://github.com/Tonyjh07/Aquarius>; the full layout reference is
> <https://github.com/Tonyjh07/Aquarius/blob/main/docs/storage.md> — this page is the quick reference.

### What this is

All local Aquarius data lives here: configuration, conversation trees, memory, attachments,
secrets, skills, plugins, logs. Everything is plain text except the secret store, so any editor
can open and change it. Uninstalling means deleting the program and this directory.

### Top level

| Name | What it is | Written by | Safe to delete |
|---|---|---|---|
| `config.json` | One line only: which profile is active. Not the configuration itself | program | No; recreated as `default` |
| `profiles/` | One subdirectory per profile, fully isolated from each other | program | Deleting it drops that profile's data |
| `README.md` | This file | program | Yes; regenerated on the next start |

### Inside a profile

`<profile>` below means a name under `profiles/`.

| Name | What it is | Written by | Safe to delete |
|---|---|---|---|
| `config.json` | Main config: models, permissions, UI, voice, plugins | settings window / user | No; the template is rewritten |
| `sandbox/` | The assistant's own workspace, writes here need no confirmation | assistant | Yes |
| `memories.md` | Global memory | assistant / user | Yes; the assistant forgets it |
| `conversations/` | Conversation trees, one JSON per conversation | program | Yes; that conversation is gone |
| `conversations/<id>.json.bak` | Previous generation, 3 kept by default | program | Yes; no rollback left |
| `conversations/<id>.memory.md` | Memory belonging to that one conversation | assistant | Yes |
| `jobs/` | Background job logs, one `.log` per job | program | Yes |
| `logs/` | Run logs, split by day and rotated | program | Yes |
| `audit.log` | Audit trail: one JSON line per model and tool call | program | Yes; history is lost |
| `attachments/` | Attachment store, file names are content sha256 | program | Yes; references break |
| `exports/` | Default destination for conversation exports | program | Yes |
| `characters/` | Imported character cards, one directory each | program | Yes |
| `skills/` | Skill directory; drop one in and it is picked up | user / program | Yes; that skill disappears |
| `skill-cache/`, `skill-installs.json` | Checkout cache and install ledger for skills | program | Yes; reinstalled from the ledger |
| `plugins/` | MCP plugin declarations, one `plugin.json` each | settings window | Yes; the plugin disappears |
| `secrets.bin`, `secrets.key` | Local secret store: ciphertext and its key | program | No; every key must be re-entered |
| `gui_pos.json`, `config.json.bak*` | Main window geometry, config backups | program | Yes |

### Four things you will actually do

- **Change configuration**: use the settings window (it validates), or edit
  `profiles/<name>/config.json` directly. Restart to apply.
- **Switch profile**: edit the name in the top-level `config.json`, or start with
  `--profile <name>`. Switching swaps the whole directory.
- **Back up**: copy the whole data directory; for conversations only, copy
  `profiles/<name>/conversations/`.
- **Roll back one conversation**:
  1. Stop the program.
  2. Rename `<id>.json.bak` to `<id>.json`.

### Four things not to do

- **Warning**: editing `conversations/*.json` while the program runs loses those edits when it
  writes the conversation back.
- **Warning**: keys placed in `config.json` sit in plain text. Put them in the secret store or in
  environment variables.
- **Warning**: once `secrets.bin` is deleted, the keys in it cannot be recovered and must be
  entered again.
- **Note**: a `*.tmp` file is a half-written temporary file, absent after a clean exit.
