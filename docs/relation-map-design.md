| **锚点** Anchor | 图所依附的唯一主体 | **当前 Head 消息**——右端基准、最大权重、`focus()` 的落点 | 必需 |

### 2.1 最重要的术语拆分：**结构根 ≠ 锚点**

RSM 把「唯一、无父、豁免预算、最大权重」压在**一个**概念上。会话树里这两半落在**两个不同节点**：

| 半边 | 落在 | 理由 |
|---|---|---|
| **唯一、无父** | 结构根 `Role=root` | 会话根**天然**满足（D19 唯一实根）；它是时间轴的起点 |
| **豁免预算、最大权重、视场基准（A8）** | 锚点 = Head | Head 是「用户在哪儿」的**唯一**答案；对话在 Head 处结束，Head 是常态叶端点 |

因此图读起来是：**左 = 会话第一层（最早），向右 = 对话推进，最右叶端 = 当前（Head）**；
开窗时**视场以 Head 为右基准**（D140 起是**平移偏好** P1：整盒装得下才精确落位，装不下时让步——
见 A8/A13），而不是以根或盒心为基准。

### 2.2 Weight 必须与 degree 解耦（加严）

> **视觉显著性 ≠ 连接度。**

- `degree`（孩子数）**只允许影响布局**（兄弟槽位窗口分配，§5.1），**绝不允许影响视觉大小**；
- `weight` 由 `(类别, 是否在主干上)` 查表得出，**表必须写死并被测试钉住**：

| weight | 条件 | 直径（× 基准 dp） |
|---|---|---|
| `w3` | 锚点（Head，含 depth 0） | 1.30 |
| `w2` | 在 Head 主干路径上（`InPath`） | 1.00 |
| `w1` | 不在主干、但**是分叉位点**（存在兄弟版本） | 0.85 |
| `w0` | 其余 | 0.70 |

- **分叉位点不进直径**：分叉由**描边**表达（沿形状的细虚线外环，§3.1）——「有兄弟」这一
  事实仍然出现，但**不在大小上**。版本计数 `i` 画在**节点图形内部**（D121）。

### 2.3 版本链：域内事实与可判定边界（**已知限制**）

会话树的版本事实只有一个结构元数据：`Conversation.RevisedFrom`（新 → 旧，纯结构元数据）。
`Fresh`/`Carry`/`Clone` 三种 `KeepMode` **不持久化**——D96 的 Clone 也只在拷贝子树**根**记一条。

因此 v1 的**断言种类只分两类**（`EdgeKind`）：

| `EdgeKind` | 判定 | 图形 |
|---|---|---|
| `EdgeSeq` 顺接 | 目标节点不在 `RevisedFrom` 的值集中 | 实线 |
| `EdgeRevise` 版本链 | `RevisedFrom[目标]` 命中 | 虚线 |

- Fresh / Carry / Clone 三者**在树形上已可分辨**，但**无字段可指名**。v1 合并为「版本链」
  一种线型，不猜。
- **后续增强**：在域内为修订节点持久化 `keep_mode`，则 `EdgeRevise` 可细分三种线型。届时本节升版。

## 3. L2 编码契约：通道分配

每个视觉通道只承载**一种**语义，禁止复用。

### 3.1 通道表

| 通道 | 承载语义 | 规则 |
|---|---|---|
| **x 位置（横轴）** | `Level`（**时间**） | D127：`x = Level × 列距`（`relColGap`）。越右越新；「子恒在父之右」= 90° 硬上限（原纵梯的层序投影换轴，**通道语义不变**） |
| **y 位置（纵轴）** | 兄弟/版本槽 | D127：同父的 m 个子按**叶数加权**铺在 `(m-1)×relRowGap` 的窗口内、窗心对齐父；版本支上下分杈（可比 `git log --graph`） |
| **节点填充色** | `Level mod 4` → **深度色带** | 同层同色，沿时间轴 3~4 色轮换；`Level` 是封闭可枚举的周期量（§3.2 改判） |
| **节点形状** | `Role`（root/user/assistant/system） | 四值四形；形状是 RSM 未占用的自由通道 |
| **节点直径** | `weight` | 查表 §2.2，**与 degree 无关** |
| **节点描边** | 分叉位点 | 分叉 = 细虚线外环（不改大小，A4 的描边通道）；主干改走**边描边** |
| **节点卡底色** | 节点填充色 → **同色系淡彩**（D121） | `层色向窗底色靠拢 relCardTintF`；标签压在卡内 |
| **边线色** | `source` 的填充色 | **边的所有权**——与目标无关（§3.3） |
| **边线型** | `EdgeKind`（版本链） | 顺接实线 / 版本链虚线（§2.3） |
| **边描边** | `InPath`（主干，A11） | 主干边垫一条**窗底色粗线**再压本色细线（D121） |
| **箭头方向** | 对话推进方向 | 恒为 **父 → 子**（提供者 → 消费者；横轴上恒指向右） |
| **标签可见性** | `weight ≥ 阈值`（且 zoom ≥ 下限） | 稀缺资源的二次分配（A5） |
| **字号** | `zoom` | `clamp(12 × zoom, 10, 16)px`，A9 |
| **弧度** | *（缺省）* | 恒为直线，不编码任何东西 |

### 3.1a 节点卡：标签入内（D121）

节点 = **卡片** `[形状徽标 | 标签]`：徽标是 `Role` 四形 × `Level` 色的填充形状，居于卡左；
卡内上下左右各留内边距（菱形尖/空心圆不被切边、分叉虚线外环不越出卡界）。

- **版本下标画在图形内部**（白字居中）：`i`（第几个版本）写在**形状里**、`n` 暂不落；
- **分叉虚线外环沿节点自身形状走**（圆走圆、方走圆角方、菱形走菱）；
- 标签画在**卡内**：最多 `relLabelLines=3` 行换行，行高显式钉 `字号 × 1.25sp`，卡片高度 =
  max(徽标高, 行数×行高) + 内边距；`relGeo` 的 `HalfH` 按**最坏缩放**预留（zoom 下限处字号
  钳 10sp、盒宽随 z 缩小 ⇒ 行数最多；D126 实测修）。标签文案 = **摘要原文**，不带角色前缀
  （见 §3.2 代价条目）；
- 标签不可见时（A5 预算 + zoom 下限）**退化为裸形状**——标签仍是预算，卡不是；
- **卡片占位参与布局**：`relGeo` 把「卡片半宽/半高」喂给求解器，接触推力从卡片边缘起算
  （§5.1 R6）；占位**不随 zoom 变**（否则缩放就会改布局，违反 R3）；
- **D127 横轴化**：兄弟槽距（卡片 pitch）由 x 轴方向定义——`pitch = max(卡宽, 静息长度) +
  槽隙` 即**列距** `relColGap`，层间不再另设距离。

> 屏幕几何一律经 **有效缩放 `z = zoom × PxPerDp`** 换算（`toScreen` 唯一定义）：徽标、
> 卡片内边距、边宽、虚线、箭头都乘 `z`，字号走 `sp`（由 Metric 换算）。

### 3.2 改判：颜色的投影对象是 `Level`，不是 `Role`

RSM A2 规定「颜色是**关系类别** kind 的投影」。本项目**刻意改判**为「颜色是**层号**
`Level mod 4` 的投影」，`Role` 移交形状通道。

- **理由**：对话树的时间层序是最强的阅读线索（越靠右 = 越新 = 离「现在」越近）。深度色带让
  「这段对话有多长、我在第几层」一眼可读；而 `Role` 只有四值、已由形状完全承载。
- **底线**：颜色仍**不承载独立语义**——它是一个封闭可枚举量的投影，图例可完整解释。A2 的
  立意（图例与语义不脱钩）成立。
- **代价**：远距离（低 zoom）下形状退化、颜色主导——曾用「低 zoom 标签补 `Role` 前缀」补偿，
  **2026-10-19 撤掉**（用户批注「看形状看得出来，不用前缀」）：形状在标签可见的全部 zoom 档
  都在，前缀是把已画出的信息再说一遍，只会占掉标签宽度、挤掉真正的摘要。低 zoom 的补偿改为
  「标签按预算逐个隐藏」（A5），不动文案。

**调色板**：深度色带 = 4 个颜色令牌 `depthMap[0..3]`，深浅两版各一套，按 §15.4/D61
「加色不改代码」纯数据预设落（`palette` 结构增 `depthMap [4]color.NRGBA`）。浅色版以品牌色
`#00AEEF` 为首色族；深色版压低明度、保证相邻色相在深底上仍可分辨（相邻两色相 ≥ 40°）。

### 3.3 边：所有权 + 类型 + 关系三元组

```
(source色, source层号)  ──箭头──>  (target色, target形状)
      └─ 谁在往下长 ─┘                └─ 谁接话 ─┘
```

- **边色 = source 的填充色**（= source 的层号色）——「谁依赖谁」与「谁断言的」解耦；
- **主干描边**是节点通道（§3.1），不是边通道——边不区分主干/支线，避免与线型冲突；
- **分叉位点**的细虚线外环与主干实心亮环可叠加（同一节点既是主干又是分叉位点很常见）。

### 3.4 关系陈述文案（`statement`，§6.3 派生函数之一）

悬停节点时的一行陈述，**必须自足**（不要求用户回查 tooltip）：

| 情形 | 文案 |
|---|---|
| 主干上游 | `你：上一轮你说的话（当前对话的主干）` |
| 主干下游 | `AI：对上一轮的回答` |
| 非主干版本 | `你：第 2/3 个版本（修订而来）——未走的分支` |
| 系统节点 | `系统：人格快照（会话首节点）` / `系统：压缩摘要（水位节点）` |
| 会话根 | `会话：<标题>（第 1 层，共 N 条消息）` |

（悬停出示暂缓：D121 实测「tooltip 太大」，文案派生 `relStatementOf` 与其测试仍在。）

## 4. 公理集

这是可被**检验**的部分。每条公理给出违反后果与**守门测试**。右列是与 RSM v1.2 的编号
对照——两套编号**不再同号异义**（v1.0 嫁接版的冲突源）：本表以项目编号为准，评审时按对照列
回查 RSM。

| # | 公理 | 违反后果 | RSM 对应 | 守门测试 |
|---|---|---|---|---|
| **A1a** | 结构根唯一且无父 | 多根 → 时间轴无处起步 | A1（半） | `deriveLevels` 恰有一个 level=0 节点 |
| **A1b** | 锚点在任何预算下恒存在且豁免预算 | 图失去右端基准，退化为毛球 | A1（半） | `budgetFilter(maxCount=1)` 结果 == `{Anchor}` |
| **A2** | `Level` 是封闭集；颜色是其**投影**而非独立属性 | 图例与语义脱钩，颜色沦为装饰 | A2（改判对象 Level） | `paletteOf` 是 `Level mod 4` 纯查表 |
| **A3** | 断言方向恒为 父 → 子 | 箭头语义不可读，必须回查 | A3 | 每条边 `level(from) < level(to)` |
| **A4** | `weight` 独立于 degree | 分叉点支配版面，语义信息丢失 | A4 | 性质测试：把某节点孩子数改成 5，`weightOf` 不变 |
| **A5** | 标签是**预算**，`weight` 低于阈值者不显形 | 缩到极限标签糊成一片 | A5 | `labelVisible` 阈值单测 + 缩放时标签数单调不增 |
| **A6** | 节点与断言**联合**过滤；被裁掉节点所涉断言一并消失 | 悬空边 / 边数与节点数不一致 | A6 | 切片后 `visibleEdges ⊆ visibleNodes × visibleNodes` |
| **A7** | 总量与已呈现量**同时可见** | 用户无法判断看到的是全貌还是切片 | A7 | 状态行文案恒含 `Total` 与 `len(visible)`；两者分源 |
| **A8** | **锚点 = 视场右基准**（D140 起降为**平移偏好**）：整盒装得下时 Head 落右基准位；装不下或与「盒在视口内」冲突时让步（Head 仍须在场，A12） | 图不成为时间轴；「现在」的位置变成尺寸巧合 | A8（改写：视口原点 → **右基准点** → D140 **偏好**） | 装得下时 `fit/focus` 后 Head 屏幕 x = `relAnchorDatumX × 视宽`（误差 ≤ 1dp）；装不下时只断言 Head 卡片在视口内 |
| **A9** | 字号 = `f(zoom)` 且钳制；**越界降级为平移** | 缩放时字号失控；越界静默失效 | A9 | 字号钳制单测 + 越界手势转 `pan` 的状态机测试 |
| **A10** | 每个非根节点携带 `ref`，点击 → 定位该节点 | 图从「索引」变成「死巷」 | A10 | 点击节点注入的 `inCh` 载荷 == `/goto <id>` |

## 5. L3 行为契约

### 5.1 布局：时间轴几何 + 常驻物理内核

**可替换轴**（§8）：几何是轴之一。本项目的几何 = **时间轴横树**（D127）：

```
restX(i) = restX(parent) + relColGap          // 时间：层号 → x（根 = 0，Head 在最右）
restY(i) = 兄弟窗口中心                        // 版本/支线：同父 m 子按叶数加权铺开
窗口(i)  = [Σ叶数×relRowGap] 的纵向带，窗心对齐父；子按叶数比例分割
```

- **「子恒在父之右」** = 90° 硬上限（原纵梯「子恒在父之下」换轴，R4 由 x 单调承担）；
- 兄弟**不靠斥力挤出来**：槽位由构造保证（叶数加权窗口 + 顺序 dodge 保最小槽距——
  D126 修订：等距铺开曾把深层巧合节点压成重叠卡）；
- 卡片 pitch = `max(卡宽, 静息长度) + relSlotGapDp` 即**列距** `relColGap`。

**物理内核（D128 转正 = 源档；D127 力积分档保留为对照回退）**：**源档**是三个直接改坐标的
通道 + 一条阻尼时钟（不是力积分），参数与算法逐值逐行取自 RSM v1.2 附录 B 与源实现的
`forceHelper.ts`：

| 通道 | 内容 |
|---|---|
| ① 弹簧（位置式） | 把「子—父」距离拉到 `relSrcEdgeLength = 200dp`，两端按权重分摊位移、等大反向（方向 = 当前连线方向，**不看静息槽位**） |
| ② 引力（位置式，**均匀树锚**） | 把**整树**朝锚点平移 `gravity(0.1) × friction × (锚点 − 盒心)`——**只平移、零内部应力**。源实现是「每节点按到固定点距离比例移动」= 收缩，会把长链压成球（实测 chain200 压到 40dp 列距、卡片全叠）；本档改均匀口径，形状交给 ① ⑦，树锚只管不漂 |
| ③ 斥力（位置式） | 全对，`(rep_i+rep_j)/d²`（`repulsion = 900`），**累加进第二位置缓冲 pp**（源实现的 pp 双角色：既当速度基准又当斥力累加器——刻意保留，见下） |
| ④ 速度通道 | `p += (p − pp) × friction`，然后 `pp = p` ⇒ 「速度」的真实语义 =（弹簧+引力的即时位移 − 斥力的累积量），三个通道因此并非同一时钟 |
| ⑤ 时钟 | `friction` 每步 `×= 0.992`，跌破 `0.01` 即判停 ⇒ **步数 = ⌈log(0.01/0.2)/log(0.992)⌉ = 373，与规模无关**（60fps 下 6.2s）；拖拽起始 warmUp `×0.8` ⇒ 346 步 |
| ⑥ pin | 拖动中被拖节点不参与任何通道的位移（仍被弹簧拉、被斥力推），位置由帧层每帧写回 |
| ⑦ 结构锥形（本仓新增，D129） | 子相对父的水平距不足 `半宽和` 时按 `k × 缺口 × friction` 推（`relSrcConeK = 2.0`）。**连续通道、不钳位**｜越接近满足推得越轻 ⇒ 永不超调；R4「子恒在父之右」由它承担（五方案比较见 §5.4） |
| ⑧ 卡片接触（本仓新增，D129，R6） | 两卡在两轴上都分不开时沿**最小穿透轴**以 `pen × relPhysPushK × friction` 相推（排除祖先-后代对；连续、不钳位，融进斥力同一遍 O(n²)） |

- **为什么时长必须是这个形状**（A15）：时长由**显式日程**决定，而不是「有多少东西要排」。
  源实现实测 373 步 × 16ms = 5968ms、浏览器实测 5949ms，且 16/51/134 节点三档移植步数
  全是 373——本档逐夹具复现了这一点（见 §5.4）。代价是它同时是**代理判据**（A17，见下）。
- **播种**：开窗首帧 / 全新图 = 向静息盒心收缩 `relSeedShrink`（确定性、可复现；源实现
  是画布内随机初始 ⇒ 终局不可复现，本档不继承）；数据变更 = 按节点 ID 保留旧位置；
- **静止时** `snapToAnchor` 把整树平移到树锚（纯平移，不改相对位置）；源实现本身无锚定。
- **卡片接触通道**（D129，R6）：D127 的轴隙接触推力融进源档斥力的同一遍 O(n²) 配对
  （最小穿透轴、排除亲属、连续不钳位）。实测卡片面积重叠率 star30 0.78→0.58、rand50
  0.69→0.39；但 binary4 0.53→0.52、rand200 0.72→0.82（无改善）⇒ R6 部分达标。
- **D127 对照档**（`AQUARIUS_REL_PHYS=d127`）：半隐式欧拉力积分（每帧 12 子步）+ 边弹簧
  （拆轴 X 2.0 / Y 1.0）+ 卡片接触推力 + 树锚（均匀外力，只平移零内应力）+ 判据 = 动能残差
  `Σv² < relPhysEps × n`。两档共用静息布局、播种、pin、视场与绘制。

**每步只约束结果必须满足的性质**：

| 要求 | 含义 | 本项目落地 |
|---|---|---|
| **R1 初始无位置** | 不接受预设坐标；首帧由模拟产生 | 从**折叠播种**（确定性小抖动的收缩态）物理展开 |
| **R2 软收敛** | 迭代到残差低于阈值，而非固定迭代数 | 动能阈值 + 硬顶预算 |
| **R3 稳定态静止** | 收敛后真正停止消耗资源（可被交互唤醒） | 收敛即停帧；平移/缩放**不**触发重排；例外仅拖拽交互态 |
| **R4 弱语义约束** | 只要求「子恒在父之右」 | 静息布局 x = Level × 列距（构造上单调）；**源档物理不再保证它**（实测 3~46 处违反，待补，见 §5.4）|
| **R5 度数解耦** | 高度数不得把邻居推出视野 | 接触推力封顶；weight 与 degree 无关（A4） |
| **R6 卡片不深压** | 卡片要装标签 ⇒ 接触从卡片边缘起算 | 轴隙按卡片半宽/半高，穿透限幅 |
| **R7 求解必须渐进** | 每步产出可渲染的中间态 | 常驻物理：任何时刻都在渲染真实中间态 |

**可测性口径**：坐标不确定 ⇒ **断言不变量**，不断言坐标。可断言：层序严格单调
（`level(parent) < level(child)`，= 90° 硬上限）· 卡片穿透有界（R6）· 动能降至静止 ·
无 NaN/坐标爆炸（有界盒）· 同输入可复现（两次构造逐点相等）。**确定性的部分**（层号、槽位、
调色板、权重、预算、标签阈值）全是纯函数，逐个测。


- **FITTING 是独立阶段**（RSM v1.1）：没有它，「入场动画」与「布局收敛 / 视场适配」会被误
  当成同一件事（原型机正是把它们硬拆成「动画时长 + 回调 + 延时 + 淡入」四段，全是死配置）。
  本项目 FITTING = **按当前盒取景**（装得下时 P1 Head 右基准位 + P2 纵向盒心居中；触底档退化为
  Head 在场 + 平移探索），由 settled 信号驱动、跟随收敛即停；
- **数据变更**走 SETTLING（保留旧位置增量重排）但**不重置视场**、不入场动画——一条新消息
  不该让整棵树重新长一遍；
- 拖拽是 R3 的**交互态例外**：松手即采纳槽位、回 SETTLING 到新形状静止。

### 5.4 运动语义与待办清单状态（D129 更新）

**转正前的实测基线（D127 力积分档）**：常见树 ~1–2s（≤180 帧）内落定；200 节点纯物理
步进 0.23ms、物理仿真帧 0.77ms、拖拽帧 0.94ms（60fps 预算 ~5%，0 allocs）。**收敛时间是
规模相关的涌现值**：卡片占位下 colGap ≈ 328dp，chain60 需 3719 步（62s@60fps）才到静息位，
而帧层预算是 15s ⇒ 实际观感是「展开到 ~81% 被认账停住」。

**D128 转正后**：时长改为**配置项**（`relSrcScheduleSteps = 900` 帧 = 15s 上限，衰减率由它
反推）+ **逐帧位移早停**（`relSrcSettleEps = 0.3dp/帧`）⇒「到点」或「到位」都停、取先到者。

### 5.5 窗形与性能纪律

- **窗形**（DESIGN §15.7 常规窗）：**左栏会话选择（列表）+ 右栏关系图 + 底部状态栏**。
  720×560（min 620×360），右栏自适应；左栏**可收起**（展开 200dp / 收起窄轨 30dp，§6.4a）。
- **状态栏**恒显（§6.4）：`共 N 条 · 呈现 M` + zoom 百分比 + 「−/＋」预算 + 「**装下整树**」（D140 改名）+ 三个聚焦域 + 色带/形状图例。
- **性能纪律**：
  1. **视口裁剪**：只绘制与视口相交的节点与边；绘制另套**视口 clip**（D121 实测修）；
  2. **懒重排**：平移/缩放/悬停**不**触发重排；例外仅拖拽交互态（帧预算 `relSettleFrames`
     封顶，收敛即停）；
  3. **预算上限**：节点数超 `hardCap = 240` 时优先收窄 `maxDepth`（砍远端整层）而非逐个
     截断，保证「主干完整 + 远端按层消失」的语义（A6）；
  4. **档位**（D126 复测，Ryzen 7 8700F）：200 节点纯物理步进 0.23ms/帧（12 子步，0 allocs）、
     物理仿真帧 0.77ms、拖拽帧 0.94ms ⇒ 60fps 预算 ~5%。基准采样须 ≥1s。

## 6. 数据契约

### 6.1 `port` 侧只读快照（`internal/port/tree.go`）

```
TreeGraph {                    // D112②：整树只读快照，一次原子发布（复用 D80 发布点）
  Anchor : MessageID           // 当前 Head —— 锚点（A1b）
  Nodes  : []GraphNode         // 按 (Level, CreatedAt, ID) 定序 → 布局可复现
  Total  : int                 // 节点总数（A7 的「共 N」）
}

GraphNode {
  ID          : MessageID
  Parent      : MessageID      // 结构根为空串
  Role        : Role           // root/user/assistant/system（类别，§3.1）
  Snippet     : Text           // 渲染文本首行片段（摘要）
  CreatedAt   : Time
  EdgeKind    : EdgeKind       // 与父边的关系：EdgeSeq | EdgeRevise（§2.3）
  SiblingIdx  : Int            // 自身在同父中的下标（版本 i/n 的 i）
  SiblingCount: Int            // 同父孩子总数（n）
}
```

**分工纪律**：`port` 只给**树事实**。`Level`/`Depth`/`InPath`/槽位/坐标/配色**一律不在 port
里**——它们是 UI 侧派生量（铁律 5 + D80 口径）。app 侧沿用 D80 同款
`atomic.Pointer[快照]`，发布点 = 构造完成 + 每次 `Handle` 返回前；UI 事件循环 goroutine
无锁读，**只读、无变更入口**。右图数据面无需扩展到「任意会话的树」：左栏点会话 = 投
`/switch <id>`（D75），app 换会话后同款发布点自然重建快照，右图自动重锚到新会话的 Head。

**左栏数据面**（新增只读端口）：`SessionLister { List() []SessionSummary }`
（`ID/Title/UpdatedAt/Messages/Current`；数据源 `ConversationStore.List`；app 实现、UI 消费）。

### 6.2 UI 侧派生量（纯函数，`uigui` 内）

| 派生量 | 定义 | 复杂度 |
|---|---|---|
| `Level` | 到结构根的跳数（根 = 0）→ **x 轴** | O(n) 迭代 |
| `Depth` | 到锚点的跳数（锚点 = 0）——只喂预算/权重，**无视觉通道**（已知限制，§10.4） | O(n) 无向遍历 |
| `InPath` | 根 → 锚点唯一路径上的节点集合 | O(n)（A11） |
| `Visible` | 预算切片结果（节点集 + 边集） | O(n log n) |
| 兄弟槽位 | 每节点子树的叶数加权纵向窗口 | O(n) |
| 坐标 | 物理内核（弹簧 + 接触 + 树锚）的收敛结果 | O(n²)·对（接触）/ O(n)·步 |

### 6.3 渲染层唯一需要实现的派生符号

```
visibleNodes(G, budget)     → [Node]       // 锚点恒留；其余按 weight 降序截断（A1b, A6）
visibleAssertions(G, nodes) → [Assertion]  // 两端都在 nodes 中的断言（A6）
colorOf(n)                  → 深度色带[Level mod 4]
cardTintOf(n)               → 层色 → 同色系淡彩（节点卡底，D121）
shapeOf(n)                  → Role 四形
scaleOf(w)                  → 直径（查表，degree 无关，A4）
strokeOf(n)                 → 分叉虚线环（主干走**边描边**，D121）
cardHalfOf(n)               → 卡片半宽/半高（喂给布局器：接触从卡片边缘起算，R6）
labelOf(n, zoom)            → 可见? / 文案（weight 阈值，A5；文案 = 摘要原文）
statementOf(n)              → 一句话关系陈述（§3.4）
centerOf(anchor)            → Point        // 布局器输出，不窥探内部（A8）
datumOf(anchor, view)       → Point        // 右基准屏幕落点（D127：viewW × relAnchorDatumX；D140 起是偏好）
boundsOf(visible)           → Box         // 盒优先取景的输入（A13；D140 用**当前**位形的盒）
```

### 6.4 状态栏口径（A7 的落点）

```
会话：<标题> · 共 N 条 · 呈现 M    [−] [＋]  缩放 100%  [装下整树] [回到初始态] [聚焦当前历史] [聚焦当前节点]
图例：▨层≡1(mod4) ▨层≡2 ▨层≡3 ▨层≡4    形状：□你 ●AI ◇系统 ◯会话根
```

`N` 恒来自快照 `Total`，`M` 恒为实际绘制节点数——两者**不得**由同一个数推算（A7 的诚实性）。
预算只有 −/＋ 两档：会话在默认预算内就是全量，原先那颗「展开全部」点了没有任何变化
（2026-10-19 用户批注「没什么效果，删了」），上限仍为 `relHardCap`。

### 6.4a 左栏可收起（2026-10-19 用户批注）

左栏（会话选择）可在**展开态 200dp** 与**收起态窄轨 30dp**之间切换，钮在左栏标题行右端
（收起后移到窄轨顶部居中）。收起把宽度让给关系图——长会话横向本来就不够看，选完会话就
不必再占 200dp。收起是**本窗帧态、不落盘**（临时视图选择，不是配置）。

同一条标题行上还有一颗 **`＋` 新建对话**（2026-10-19 用户批注「这里加个加号，功能是新建
对话」，指位 = 「会话」右侧、收起钮左边）：点击投 `/new`（与键入同路径、壳内不建会话），
内核对完发布新快照，左栏与右图随签名单帧刷新。钮序 `＋` 在左、`◀` 在右——收起钮语义是
「把这条栏收掉」，贴边最右更顺；收起态该行整条不画，故 `＋` 在收起态不存在。

### 6.5 抽象成立的判据

所有物理迭代、收敛、tooltip、缩放、culling 都在 §6.3 的符号**之外**——它们是**可替换的
实现**，不是语言的一部分。一个新后端若能在**不理解 Gio 任何概念**的前提下，仅凭 `TreeGraph`
快照 + §6.3 符号渲染出**语义等价**的图，则抽象成立。

## 7. 必要 vs 偶然（剥离清单）

| 属于设计语言 | 属于偶然实现 / **缺陷** |
|---|---|
| 根/锚点拆分（§2.1） | 用 `nodes[0]` 当锚点的字面判断 |
| 颜色 = `Level mod 4` 的投影（§3.2 改判） | 调色板散落在绘制代码里的 `switch level` |
| 权重独立于 degree（A4） | 具体直径数值 1.30/1.00/0.85/0.70 |
| 类别 = 形状（A2 移位） | 形状绘制的具体路径数据 |
| 标签 = 预算（A5） | 阈值具体取值 |
| 节点与边联合过滤（A6） | **未做**——只过滤节点、边留给渲染器兜底 |
| 总量/已呈现并显（A7） | 由 `len(nodes)` 兼充「共 N」（把切片说成全貌） |
| 锚点 = 视场右基准（A8） | 读布局器私有字段 / 每帧重算锚点位置 / 拿盒心冒充基准；**或把「右基准 + 纵向 Head 居中」当硬契约**（D140 实证：Head 在盒下端时整盒被顶出视口） |
| 字号钳制 + 越界降级为平移（A9） | `[10,16]` 像素、`1.49999` 魔数补偿 |
| 主干可辨（A11） | 用「最后绘制的边」冒充当前路径 |
| 拖拽 = 临时固定 + 松手采纳槽位（A12） | 拖到哪钉哪且永不收敛；或松手弹回旧形状 |
| 视场适配 = 盒优先（A13，D140） | 只 fit 盒心不认锚点；长会话硬 fit 到不可读；**或拿静息盒当基准去适配物理平衡态**（D140 实证：纵差 1.5~2.4×） |
| 时间轴几何（D127：x = Level、y = 版本槽） | **纵梯几何**（D127 已废除：y = Level 的层序投影是同一 Level 语义的旧轴分配，不是新语义） |
| 可复现终局 + 槽位按 ID 持久（三条有意改写） | 依赖随机初始条件 / 重排即丢手动摆放 |
| 标签入卡 + 卡底随层色（D121 §3.1a） | 标签画在节点外侧、卡底用固定灰 |
| 接触从卡片边缘起算（R6） | 按中心距排斥（卡片必然压字） |
| 断言自带种类（§2.3） | **由 source 的 kind 反推版本链**（应查 `RevisedFrom` 显式映射） |
| 两态生命周期 + FITTING（§5.3） | 动画时长 + 回调 + 延时 + 淡入的四段式 |
| — | **`depth` 永不产出 0**（锚点自身不算距离——本项目显式给 0） |
| — | **`n <= maxCount` 的 off-by-one**（多画一个） |
| — | **边悬空**：裁掉节点后边仍在（违反 A6） |
| — | **零值 `relPin{}` 把结构根悄悄钉死**（Go 零值 Index=0）——故「无固定」用显式 `Valid` 表达 |

| 帧层 | `relmap_frame.go` | `fitView` + fit 后**右基准平移**（`offX = relAnchorDatumX×viewW − headX×z`；平移会出界则保持盒心对准）；触底回退仍走 `fitFollow`（目标位同步为右基准）；`focusAnchor` 改为右基准落点；新增 `relAnchorDatumX ≈ 0.72` |
| 卡片 pitch | `relmap.go` | 兄弟 pitch 喂 x 轴（`relSlotPitch` 沿横轴定义）；卡片几何不变 |
| 测试 | `relmap_layout_test.go` / `relmap_frame_test.go` | 纵梯断言换横轴口径：层序单调改 **x 单调**；adopt 带断言改横向；A8/A13 守门改右基准；A11/A12 等沿用 |
| 基准 | `relmap_anim_bench_test.go` | 横树夹具复测（收敛帧/残差预期变化） |
| 绘制 | `draw*` | **预期零改**（几何无关：边/箭头按坐标向量、卡片按节点中心） |

### 10.2 与主窗转写区的纪律对齐

- 本窗**不接**主窗专属机制：无 ULW 形状位图、无位置记忆、不置顶、无拖拽把手（§15.7）。
- 滚轮在本窗**不参与**行级手势（D71 滚轮钉点只管主窗转写区）——故「滚轮=缩放」安全。
- 缩放与 `ui.scale`/`ui.font_size`（D90 两旋钮）正交：本窗 zoom 是**窗内视场倍率**，
  字号区间 `[10,16]px` 是 A9 的排版硬约束，**不随**全局旋钮突破。
- 长按/右键命中复用 D72「武装-原位抬手」手势纪律，不与滚轮缩放抢事件。

### 10.4 已知限制与后续增强

| 项 | 现状 | 处置 |
|---|---|---|
| 左栏收起 | 收起后选会话要走「展开 → 点行 → 再收起」三步 | 接受：收起是**看图的临时态**，不是常驻态；左栏里每天都在用的东西（会话列表）不该被藏进二级入口 |

| A16/A17/A18 | 时长涌现、锚点被间接推移、判据为动能 | §5.4 三条差距 + 候选方案已备；后续决策（预计 D128） |
