## 口径

- **引号例外**：本仓中文用 `「」`，不换成 STC 默认的 `“”`（2026-11-04 拍板）。检查器报的
  G17 共 1938 处，全部按例外跳过，其余规则照改。理由与另外三条例外写在词表末尾。
- **事实不变**：只改表达。逐篇过 `git diff`，核对结论、数字、权限、默认值、跨篇链接与
  标题锚点。改标题时同步改目录链接（`guide.md` 第 1、6 节）。
- **读者分层**：用户面五篇与工程文档都把主语写全；工程文档里的几何术语、断言原文、
  引文按词表例外保留。
- **warnings 按 STC 审查规则处理**：错误级问题逐条改写或登记理由；仅改善措辞、句长的
  建议列为可选项，不因检查器报错就认定原文必须改。

## 改了什么

1. **主语 D1**：把 D1 报出的人称代词换成具体名称。用户手册换成「助手」「模型」
   「该节点」「这个按钮」，工程文档换成「Aquarius」「外部代理」「角色卡批次」等。
   用户手册的两个旧标题改成产品名或「助手」开头，目录锚点同步。
2. **行话 G6**：`落地` 按搭配换成 `完成 / 已完成 / 完成记录 / 具体做法`，`链路` 换成
   `流程`，`对齐口径` 换成 `按…口径 / 与…一致`，`无缝` 换成 `没有接缝`，`抓手` 换成
   `命中判定`，`闭环` 换成 `成对检查`。共 150 余处；几何与排版的位置术语不动。
3. **含糊词与口号句**：`非常驻` 统一成 `不常驻`（同时消掉程度词误报）；删掉
   `大部分情况` `若干` `适当` `必要时` 这类软化词；把口号式对比句拆成平实两句。
4. **术语统一**：按词表把 `人设` → `人格`、`记忆文件` → `记忆文档`、`技能包` → `技能`、
   `对话树` → `会话树`、`摘要节点` → `压缩摘要` 等叫法收齐。
5. **结构**：`docs/README.md` 的「文风」段收成一句指向，不再与 STC 各写一份规则；
   `development.md` 与 `AGENTS.md` 里指向那段的话同步改写。用户面文档清掉 `Q1` / `Q10` 一类编号引用。
