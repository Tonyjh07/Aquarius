# Aquarius v0.7.0
<!-- docs-sync: 2026-11-12 @ 151fa22 -->

第七个公开版本。这一版处理「每次都要点同意」：可以按工具设档，可以在确认框里当场改档，也可以
点一次「以后都允许」不再看见。再往前一步，能挂一个决策模型替你挡掉明显该批的请求——这一项默认
关闭，先把记录攒起来再谈放量。另有一批小改：数据目录多一份自动生成的说明、隔天再聊会自己更正
日期、注入内容默认折成一行、角色卡里的世界书按关键词激活。聊天、会话树与磁盘格式没有换范式，
替换 exe 即可升级。

## 这个版本新增

### 按工具设权限档

- 设置窗「工具与 MCP」页每一行多出三段：**默认 / 询问 / 允许**。「默认」= 跟随当前权限档，
  选「默认」就不必再想怎么恢复；
- 只有偏离的条目写进配置（`permissions.overrides`），没写过的跟权限档走；
- 这一层**两个方向都管**：`full-access` 下把某个工具设成「询问」，这个工具照样弹框。显式例外比
  全局档位更具体，收紧不该被整体档位吃掉；
- 外部代理没有稳定的工具名，单独一行「全部请求」；
- 有一份**不可覆盖的名单**照问照拒，即便这个工具设成「允许」：版本控制钩子、编辑器与代理
  设置、MCP 配置、密钥目录、系统目录。这是策略表唯一说了不算的地方。

### 确认框里当场改档

- 🔑 从「升一档」改成**直选档位**，升与降在同一张列表里。选完由内核按新档位重判这一次：
  该放行的放行；新档位判「询问」的仍会再问你一次；新档位明确不允许的当场拒绝并给出原因，
  不用点第二遍；
- 新增**「以后都允许」**：执行类按工具放行；文件类只放宽到**该文件所在目录**——写一个文件
  不该等于全盘可写。点下去就写进配置、跨重启生效，同时记一条审计，写明是哪个工具、哪个范围、
  哪一次调用触发了这条策略；
- 按钮文案带范围：「以后 `file_write` 在 `E:\project` 内不再询问」。撤销在设置窗
  「目录级放宽」区，一条一行；
- 回答回显分两种：「允许」与「允许（以后不再询问）」，否则下次不弹框时会以为哪里坏了。

### 模型辅助决策（实验性，默认关）

- 配置里有 `decide` 一段，`mode` 三档：`off`（与以前一致）、`shadow`（只记审计，不改行为）、
  `on`（按分数分流）；
- 分流用**两个条件**：`risk` 低于阈值且 `needs_human` 低于阈值才放行；「明显该拒」这一档
  默认关闭；
- **失败一律交回**：超时（默认 1500 ms）、没配端点、解析不出、模型报错，都按原来的方式问你，
  绝不默认放行；
- 启动后异步发一次最小请求把连接拉热——本机冷启动要几秒，不预热则第一次判定必然超时；
- 每次判定记 `{模型, 结论, 分数, 阈值, 耗时}`，模型批的与你批的在报告里分两份；
- 阈值留的是默认值，**没有用本仓真实记录标定过**。先跑一段 `shadow` 看记录，再考虑开 `on`。

### 数据目录里的一份说明

- 首次启动会在数据目录写一份 `README.md`：中英同文件，讲这个目录里每个文件与子目录是干什么的、
  哪些可以手改、哪些由程序管理。路径与目录结构以 [storage.md](../storage.md) 为准；
- 首行带版本号。程序更新后版本号变了就重写；内容没变则不动；
- 你自己写的那份不会被覆盖，只在日志里提示一句；
- 写不出来不拦启动。

### 隔天再聊，日期自己更正

- 会话里的人格会记住「今天」是创建会话那天。跨过零点再来说话，新日期的第一条消息之前会落一条
  日期说明，把旧日期改正过来；
- 这条说明是一条注入节点：转写区看得见、不触发新一轮，一天最多一条。

### 注入默认折成一行

- 注入内容在转写区折成一行：`▸ 指令更新 · 日期变更`、`▸ 工具注入 · think`。点开才铺触发状态
  与正文，再点收起；
- 开合是视图状态，不进上下文，清屏时复位；
- 类别按来源自动取词，没见过的来源照原文显示。

### 角色卡世界书按关键词激活

- 卡里带触发词（`keys`）的条目，按最近几条消息命中；命中后按 `order` 装进上下文预算，
  装不下的整条不激活——不会把一条切一半；
- 常驻条目照旧整段接在人格后面；
- `/lore` 看这一轮激活了哪些：卡名、条数、标题与 `order`、合计 token、被预算挡掉的条数；
  `/usage` 在有命中时也会多一行；
- 开关、扫描深度与预算比例在配置的 `characters.lore` 段；作者给条目设的概率不读。

### 界面细节

- 提示卡、补全候选、档位列表这些浮层改跟主题走：浅色主题白面细描边，深色主题亮一阶，
  不再一律用深色；
- 从终端启动时，运行日志回显到那个终端；双击启动不回显。

## 行为变更

- **`full-access` 不再是「什么都不问」**。这一档只是权限矩阵里的一档，你在策略表里显式设成
  「询问」的工具在这一档下面照样弹框；
- **「辅助」与「询问」目前行为相同**。决策模型是确认器的装饰器：`decide` 段开着时，凡进确认
  的都先过模型，不只是标成「辅助」的那几条；关着时「辅助」就是「询问」。这一档留着是给以后
  收窄用；
- **TUI 的确认态没变**：仍是是 / 否，改档位与「以后都允许」只在 GUI。两套界面的确认预算不同，
  这是选择，不是漏做。

## 修掉的问题

- 运行日志里几处界面文案与行话没走同一套措辞，这一版统一了一遍；
- 决策模型三题（该不该允许、风险、要不要人看）的**顺序**固定下来。同一份输入换个顺序，
  分数会明显不同，之前没有把这个顺序钉住。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行先出五步引导：选界面语言、阅读并同意条款、填模型接入（或点「稍后配置」）、
   看一遍基本用法、确认保存；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗编辑；
4. `/help` 查看全部命令。

**升级**：配置与会话都在 `~/.aquarius/`，本版磁盘格式向后兼容，替换 exe 即可，不需要迁移。
新增的 `decide` 与 `characters.lore` 两段都有默认值，不写也能跑。启动后会多一份
`~/.aquarius/README.md`，那是程序生成的说明，可以随便读，但改了会被下一次更新覆盖——想留自己
的笔记请另建文件。

**卸载**：删除 exe 与 `~/.aquarius/` 目录。

## 已知限制

- **决策模型没有标定过**。阈值是默认值，来自零星实测而非本仓记录。`shadow` 模式先跑一段，
  看「模型批的」与「你批的」差多少，再决定要不要开；
- **「禁用」不等于围栏**。这一档让模型看不见这个工具，拦的是误调，不是换路——模型可以改走 `term_exec`；
- **「以后都允许」是永久的全局放宽**，只能靠文案与审计兜，代码兜不住。撤销入口在设置页；
- **申报不等于沙箱**：外部代理自己起 shell 之后，读写与命令都不经过 Aquarius；越界读不设门禁，
  Windows 上 `.cmd` / `.bat` 形状的命令起不来；
- 沿用上一版：Linux/macOS 可构建运行，但 GUI 为降级形态（无托盘、全局热键、半透明羽化与原生
  右键菜单），语音采集仅 Windows；字体字距在 `T` 之后偏窄，根因在上游渲染库；
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。

## 校验

```text
aquarius.exe -version
Aquarius v0.7.0 (windows/amd64, go1.27.4)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。
