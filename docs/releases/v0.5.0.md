# Aquarius v0.5.0
<!-- docs-sync: 2026-11-05 @ f7abd72 -->

第五个公开版本。这一版不加新范式，把三条主线收口：界面文案收进一处取词口、运行日志收进
一处写出点、第一次启动该问的几件事收进一个五步向导。另有一轮文档按同一套中文写法重写，
以及测试并行化、内部结构收口与发版资源收口。聊天、权限模型与会话树没有换范式；磁盘上的
配置与会话格式向后兼容，替换 exe 即可升级。

## 这个版本新增

### 界面语言

- 简体中文与 English 两套界面，默认读系统界面语言，认不出回落中文。设置窗「常规」页可切换，
  改完要重启；图形界面、终端界面与命令行共用同一处取词。
- 向导第 1 页也能选，选完当场生效，离开这一页把选择写回 `ui.lang`。`AQUARIUS_UI_LANG`
  环境变量可覆盖，测试和便携安装换语言用。
- 输入框占位灰字可自定义（`ui.input_placeholder`），这一句不翻译，切到哪套语言都用你写的那句；
  留空回落内置文案，保存即生效。
- 英文界面走过一轮布局走查：修掉历史窗状态栏里 `Discard` 被切、开关掉出可视区。

### 运行日志

- 一行五段：时间 / 级别 / 上下文 / 事件 / 行动。落在
  `<data>/profiles/<profile>/logs/aquarius-YYYY-MM-DD.log`，按天切，单文件超 4 MiB 轮转一代，
  保留 7 天。
- `warn` 以上同一套单行同时进 `stderr`；图形界面双击启动没有控制台，`debug` / `info` 只在日志里。
- 级别由 `ui.log_level` 定，`-log-level` 与 `AQUARIUS_LOG_LEVEL` 可覆盖；`-log-format json`
  一行一条，`ctx` / `event` / `action` 是 key，不随界面语言变。非法值启动报错，不静默回落。
- 代码里散落的 `stderr` 直写已收口，事件 key 必带行动位，出口有测试锁守着。

### 第一次启动的五步引导

首次运行先出这一个窗，保存后主窗才起来：

1. **界面语言**：跟随系统 / 简体中文 / English，当场生效。
2. **用户协议与隐私政策**：两份正文都在这一页里，滚到底勾上「我已阅读并同意…」才能继续。
   同意记下版本号；以后正文改了只重过这一页，配置与其余四页不打扰。
3. **模型接入**：填服务商与密钥，可点「测试连通」「获取模型」。还没有密钥就点「稍后配置」，
   主窗照样能进；在那之前发消息，程序会明确告诉你「还没有配置模型提供商」。
4. **基本用法**：常用命令与手势，看一遍就过。
5. **完成**：显示将要保存的内容，密钥只显示形态，不回显明文；点「保存并继续」开始使用。

以后想再看：设置窗 →「常规」→「欢迎引导」→「打开」。第 3 页「稍后配置」只跳过本页，
不写 `model.providers`，向导也不会再弹一次。

### 文档

用户手册、用法速查、配置参考、存储说明与仓库首页按同一套中文写法重写：主语写全、结论在前、
去掉复述与软化词，按钮与菜单名统一用直角引号「」。逐篇结果与保留理由见
[stc/review.md](../stc/review.md)。

### 内部结构

- 界面侧的命令投递收成一张表：新增动作先登记命令名，结构化投递与文本拼行各走一个出口；
  与内核命令清单自动对账，改名或删命令时不会「编译照过、运行期才报未知命令」。
- 四个最长的函数各抽出一段（主输入循环、设置落盘、命令表初始化、转写区折叠条），并加了
  一条守卫：超过 100 行的函数数量只允许减少（当前 31 个，单函数上限 225 行）。

## 修掉的问题

- 首次启动时机器上还没设密钥变量，点「稍后配置」会直接退出（退出码 1）。现在照样进主窗，
  发消息时明确告诉你缺的是哪个环境变量，去设置窗补上即可。
- 密钥可用时，首页与末页的「以后再说」可以不读协议就进主窗；现在两个出口都校验同意。
- 缺少模型提供商时，发消息不再报一串底层错误，改成一句明确提示。
- 英文界面下历史窗状态栏溢出：`Discard` 被切、`Tree editing` 竖排、开关掉出可视区。
- 英文界面里仍会露出中文标点：确认卡的事实行拼成 `default · Fix bug（01K…）`，压缩摘要与
  技能回执也各带一处全角标点。判定规则从「只看汉字」扩到全角字符区，并修掉这几处拼接。
- 切换界面语言后，第 3 页的「连通正常 / 候选模型已填入」仍是切换前那句；现在存的是键与参数，
  渲染时才取词。
- 200% 字号下欢迎窗的页面滚动与步进条挤压。
- 运行日志散在多处 `stderr` 直写，图形界面启动时看不见，也分不清是谁写的。
- 日志里写入带换行的报错（外部进程的 `exit status 1\nerror: …`）会把一条记录劈成两行，
  后半行没有时间与级别；现在文本形态统一转义，一条永远一行。
- 外部代理跑到一半就退出时，已经给出的结论偶尔整段消失；现在会等协议通知收完再出报告。
- 外部代理刚启动就崩溃时，报错偶尔不带子进程的错误输出；现在会等这截输出收完再报因。
- 删除会话与保存会话撞在一起时，刚删掉的会话可能被写回来；现在两者共用同一把会话锁。
- 带空格的导入路径（`C:\My Docs\a.aqx`）经折叠条走文本命令时会被切成两段；现在按命令切分
  规则加引号。
- 协议正文的生效日期改到 2026 年 11 月 6 日；版本资源改为 0.5.0.0（此前 exe 属性页仍显示 0.4.0.0）。
- 隐私政策补上漏写的两个密钥文件名（`secrets.key`、`secrets.bin.bak`），并把「换机器解不开」
  限定到 Windows：其他平台的密钥库不是绑定本机的加密形态。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行先出五步引导：选界面语言、阅读并同意条款、填模型接入（或点「稍后配置」）、
   看一遍基本用法、确认保存；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗
   「模型服务」页编辑；
4. `/help` 查看全部命令。

**升级**：配置与会话都在 `~/.aquarius/`，本版磁盘格式向后兼容（旧会话缺的新字段按空处理），
替换 exe 即可，不需要迁移。改动配置前建议备份该目录（也可在应用内用 profile 隔离试验）。
`ui.welcomed` 缺失的升级用户，启动后会打开一次欢迎窗。

**卸载**：删除 exe 与 `~/.aquarius/` 目录。

## 已知限制

- 200% 字号下，向导第 1 页的语言选择要滚一下才能看见；首屏只放得下 logo、名字与标语。
  要「第一眼就能切语言」得再省掉 logo 与标语，那是品牌取舍，本版不改。
- Windows 为完整形态；Linux/macOS 可构建运行，但 GUI 为降级形态（无托盘、全局热键、
  半透明/羽化、原生右键菜单），语音采集仅 Windows。
- 设置窗直接配 ACP 与申报 `fs` / `terminal` 整条主线移到 v0.6.0，本版不做。
- 语音前处理（VAD、唤醒词、声纹）仍在 backlog；录音固定用系统默认输入设备，默认 60 秒、
  上限 4 分钟，不支持唤醒词与自动断句。
- 终端界面认不出 `Shift+Enter`，插话与排队回落到 `Enter` / `Alt+Enter`；语音入口仍是 `/mic`。
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。
- Go 级进程内插件尚未开放；扩展能力目前走 MCP 与技能。
- 没有「工作区」概念：文件工具使用绝对路径或会话附件，不绑定当前目录。
- 字体字距有一处缺陷：`T` 之后相邻字母会少一点间距，根因在上游渲染库，本版仍未修。

## 校验

```text
aquarius.exe -version
Aquarius v0.5.0 (windows/amd64, go1.27.3)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。
