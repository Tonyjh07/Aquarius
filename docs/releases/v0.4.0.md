# Aquarius v0.4.0
<!-- docs-sync: 2026-11-01 @ 8c593ec -->

第四个公开版本。这一版的主线是**把复杂任务交给另一个代理去做**，和**在它干活的时候你还能说话**。
另外补上了会话树的改父与树编辑模式、转写区里命令与提示的折叠条，以及程序意外退出后下次启动
把没跑完的事说出来。聊天与权限模型没有换范式；磁盘上的配置与会话格式向后兼容，替换 exe 即可升级。

## 这个版本新增

### 外部代理转交

有些活不适合由 Aquarius 的工具循环一件件拼出来——跨很多文件的重构、要反复试错的构建修复、
长链路的排查。这类任务可以**整个交给另一个代理程序**：它有自己的工具循环和自己的判断，我们只
负责把任务递过去、把报告收回来。协议是 ACP（Agent Client Protocol），走它的人已经不少，
装上就能接。

- **怎么配**：`config.json` 的 `delegate.agents` 里写一条，形状和 MCP server 一样——
  `name`、`command`、可选 `args` / `env` / `workdir`。**不发预设**：各家代理的命令名与启动参数
  由它们自己定，我们抄一份只会过时。启动时按 `PATH` 探一下，探得到的才标「可用」；探不到的
  仍列在清单里并写明原因。一条都没配时模型拿不到 `delegate*` 工具，程序照常启动。
- **怎么看、怎么改**：设置窗新增**「外部代理」**页——一行一个代理，显示命令行、可用性、缺省标记，
  可就地改命令行、启停、设缺省，另有「重新检测」（改完 `PATH` 或刚装好那个程序，点它重探一次，
  不用重启）。这一页**只改不删**，写回配置文件、重启生效。命令行也还有 `/delegate list`。
- **怎么触发**：你正常提要求，模型自己判断这活该转交，然后调 `delegate` 工具——它会先弹确认。
  转交不该由你手写任务描述：模型的活是拆任务，你的活是批准或拒绝。
- **派出去就能走开**：转交在后台跑，你切到别的会话干活也行——回来时报告已经在**发起它的那个
  会话**里等着。结束时会多一条「它的最终报告 + 一行摘要」（工具调用几次、改了哪些文件、跑了多久、
  怎么停的：正常结束 / 到输出上限 / 到轮次上限 / 它主动拒绝 / 被取消）。它中间那几十次工具调用、
  思考、计划表**不进你的对话**。
- **同时能跑几个**：每个会话最多 2 个、全局最多 4 个（`delegate.max_concurrent` /
  `max_total` 可调）；超了 `delegate` 直接回绝，不排队。单次总闸默认 30 分钟
  （`delegate.timeout_sec`），防止进程挂住。
- **边界要说清**：批准一次转交 = 批准那个程序在**它自己的判断下**动手。我们的权限等级只管自己
  的工具链，管不到它；`workdir` 是起点不是围栏；它愿意反问的权限请求会落到你的确认框，
  不愿意问的我们知道不了。**无人值守时转交一律被拒**。
- **中断的转交会被说出来**：转交在跑期间在 `<配置目录>/jobs/delegates.json` 记一条，报告落到
  会话才销账。若在它跑着的时候退出，下次启动会多一行「上次退出时中断了 N 笔转交」，
  并往发起会话补一条事实（哪件活、谁去做的、停在什么时候）。

### 生成中接着说话

以前生成中打的字只能排队，等整轮结束才发出去。现在有两个位置可选：

- `Enter`（或点发送）= **排队**：等服务完再说，落在输入框上方的**待发条**里；
- `Shift+Enter`（或 `Shift`+点发送）= **引导**：在当前这一轮做完手上的工具之后、下一次请求之前
  插进去，模型当场看见，**这一轮不结束**——回答会分成两段，你说的那句夹在中间。

两条的落点不一样，因为时间感不一样：**排队**停在待发条里，每条可以「转引导」、拉回输入框继续
改、或者撤销；**引导**直接铺在转写区末尾、长成你的一条用户气泡，比真气泡**淡一档**——它还在等
下一次请求，眼睛能分出来。气泡旁边的 `↓` 让它退回排队、`×` 丢弃。待发最多 8 条。

- **停止键**（右侧方块）也分两种情况：有**引导**待发时，打断这次响应并立刻拿那句重新请求；
  只有排队时，停手，清单留着不自动续跑。已生成的部分照常保留。
- **切会话会丢清单**（它属于那个会话的内存），会留一行提示说明丢了几条。
- **快捷键可改**：`ui.keys` 里可改这三键的绑法，启动时校验——键名写错或两个动作撞在同一个组合上
  会直接报错并指出是哪一条。终端界面认不出 `Shift+Enter`，回落到 `Enter` / `Alt+Enter`，
  状态行报待发条数、空输入时 `Ctrl+U` 撤销最后一条。

### 改父与树编辑

一条消息挂在谁下面，决定了「从这里往后发给模型的是哪一串」。本版可以把它（连同下面整棵子树）
搬到别处：

- `/reparent <节点 id> <新父 id>`，两边都支持唯一前缀。新父不能是会话根（人格会退出上下文）、
  不能是自己或自己的后代、也不能就是现在的父；改父不动「当前到哪条」，也不动版本链。
- **关系图里拖**：先打开状态栏右端的**「树编辑」**开关。开着时整块图区围一层光晕、左上角出现
  「编辑树 · 拖动节点改挂 · 已改 N 处」——随时看得见「现在拖一下会不会改到结构」。把节点拖到
  别的节点附近（48dp 内），松手最接近的那个就成为新父（挂为最后一个孩子）；拖了但没靠近任何节点，
  就只是换了位置。压在自己的后代上会被拒绝并说一句。
- **攒着改**：拖动只改内存，图立刻反映新接法，**退出这个模式时才统一保存**一次。有改动时退出
  先问「保存」，拒绝再问「放弃」，再拒绝就取消（留在模式里）。保存前比对一次装配条数，
  **变少了要你先确认**（那部分提示不再回传给模型），变多了只提示。
- **每次搬运都留一条溯源记录**，`/reparent --undo` 反做最近一次并把这条记录消费掉。
  删除一个子树时，里头若有别的节点的「修订自」记录，那条溯源一并清掉——确认句会先讲明件数。

### 转写区里的命令与提示

命令行与它的回执以前各占一行（提示还带着 `[notice]` 前缀），一次工具往返下来屏幕很吵。现在：

- 连续的命令合成一条**命令折叠条**，默认一行「折叠 N 条命令 · 点击展开」，点开才铺命令行与输出；
- 命令行不再占用户气泡，结果也不再借助手气泡的底板；中间的发言或回答会把条隔断，再来的命令另起一条；
- 回执类提示（已恢复、已切换、正在录音、密钥冷却、降级、摘要已生成）收进折叠条；
  **改变了本轮上下文预期**的提示（压缩失败回退裁剪、硬保底截断）仍留在转写里，一行淡橙小字、立刻可见。

### 重启后把没跑完的事说出来

后台任务与转交现在都记一份台账（`jobs/ledger.json` / `jobs/delegates.json`）：起手记一条，
终态只标状态，**报告真正落到会话才销账**。程序意外退出后下次启动会读它——还在跑的按 pid 只探活
不接管，已经没了但退出码未知的补一条事实（含日志尾），并说明「上次退出时有 N 笔没跑完」。
台账坏了不挡启动。

## 修掉的问题

- **报告落到错误的会话**：后台任务或转交跑完，报告以前会塞进**你当前打开的那个**会话；
  现在按发起时会话异地落地，切走再切回来报告还在，目标会话被删掉就丢弃并记日志。
- **退出时报告还没写盘就被当成办完**：销账与落盘原本不是同一件事，断电式退出会丢报告；
  现在先落地再销账，重启对账能区分「已结束、报告未送达」。
- **程序退出时后台任务尾巴被截断**：关停时不再立刻掐断任务管理器，等跑完的那个任务把尾巴写完。
- **首启引导窗消失得无声无息**：没有可用密钥时点「跳过」，以前只往 stderr 打一行就退出 0，
  双击启动没有控制台，看起来就像窗口自己没了；现在先弹系统消息框再退出。有密钥时点「跳过」
  会记下「已看过」，不会下次启动又弹一次引导窗、同时再叠一个主窗。
- **启动时读不到「当前会话」被当成「不在会话里」**：刚开始那几秒会把每一次转交的权限请求都拒掉；
  现在读不到就退回确认框，不替你做决定。
- **历史窗每行前那个头像位**：没有角色卡的会话都显示一个像没加载完的圆角方块，还白占 30dp；
  整个槽位去掉了。
- **状态行里的会话标题**：左栏已经标了当前会话，标题是重复的，而且长度不设限——长标题会把
  右侧包括树编辑开关在内的控件挤出去。状态行现在以定宽的条数开头。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行会生成配置指针与模板，先打开**配置引导窗**：填 provider 名、接口地址、密钥与模型名；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗「模型服务」页编辑；
4. 保存后重启即可对话；`/help` 查看全部命令。

**升级**：配置与会话都在 `~/.aquarius/`，本版磁盘格式向后兼容（旧会话缺的新字段按空处理），
替换 exe 即可，不需要迁移。改动配置前建议备份该目录（也可在应用内用 profile 隔离试验）。

**卸载**：删除 exe 与 `~/.aquarius/` 目录。

## 已知限制

- Windows 为完整形态；Linux/macOS 可构建运行，但 GUI 为降级形态（无托盘、全局热键、半透明/羽化、
  原生右键菜单），**语音采集仅 Windows**。
- 外部代理只做 ACP 六方法：`fs/*` 与 `terminal/*` 一律回「不支持」，代理要用文件与命令就得自己起进程
  去操作；多会话并行、会话恢复（`session/load`）尚未做，每次转交都是全新会话，追问要重述背景。
- 转交只收回报告与一行摘要；它中间的工具调用、思考、计划表不进你的对话，也不落盘。
- 角色卡只读：不能编辑或导出卡；世界书只注入「常驻」条目，按关键词检索、`order` 淘汰尚未实现；
  正则脚本、表情/背景/语音资产保留但不执行；卡正文里的 HTML 按纯文本显示。
- 会话导出里 Open WebUI 只能读、不能写；`chatgpt` / `openai` / `sillytavern` 是有损格式，
  `openai` 与 `sillytavern` 只带当前那条链。
- 本地 whisper 需要自备 ggml 模型文件，不随二进制分发；云端识别与合成需要联网，音频会发送给你配置的
  服务商，除非识别方式选了「本地 whisper」。
- 录音固定使用系统默认输入设备，默认 60 秒、上限 4 分钟；不支持唤醒词与自动断句。
- 终端界面认不出 `Shift+Enter`，插话与排队回落到 `Enter` / `Alt+Enter`；语音入口仍是 `/mic`。
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。
- Go 级进程内插件尚未开放；扩展能力目前走 MCP 与技能。
- 没有「工作区」概念：文件工具使用绝对路径或会话附件，不绑定当前目录。
- 字体字距有一处缺陷：`T` 之后相邻字母会少一点间距，根因在上游渲染库，本版仍未修。

## 校验

```text
aquarius.exe -version
Aquarius v0.4.0 (windows/amd64, go1.27.3)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。
