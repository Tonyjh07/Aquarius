# Aquarius v0.3.0
<!-- docs-sync: 2026-10-30 @ 68d8f24 -->

第三个公开版本。这一版的主线是**把会话搬出去、搬回来**和**用现成的角色卡开聊**，另外补上了输入框的参数提示、按份数轮转的会话备份，以及两处配置侧的补强。聊天与权限模型没有换范式；磁盘上的配置与会话格式向后兼容，替换 exe 即可升级。

## 这个版本新增

### 导出与导入

斜杠命令 `/export`、`/import`，历史窗左栏标题行也各有一颗「导出」「导入」钮。

导出分两种用途：

| 用途 | 选这一档 | 带走什么 | 会丢什么 |
|---|---|---|---|
| 备份、换机自带 | `aqx`（缺省） | 消息、分支、版本关系、附件原文件全在，导回来还是同一棵树 | 不丢 |
| 给别的程序读 | `chatgpt` | 树形结构，分支都在 | 思考过程、工具调用与附件原文件 |
| 给别的程序读 | `openai` / `sillytavern` | 只带当前那条链 | 旁支、思考、工具、附件都不在其中 |

保存框里的**「保存类型」下拉框就是格式选择器**，选中哪一档就写哪种格式，落点扩展名跟着改；命令行等价写法是 `/export --format chatgpt --path …`。不带 `--path` 时落在 profile 的 `exports` 目录，文件名取自会话标题；同名不覆盖，自动加 `-2`。有损格式导出后会逐项列出「没有带过去的内容」，包括旁支上还剩多少条消息——看到这份清单再决定够不够用。

导入认得这几家的东西：`aqx`、ChatGPT 导出的会话 JSON、Open WebUI 导出的会话、OpenAI 消息数组、SillyTavern 聊天记录。**一律落成新会话**，不覆盖你现有的任何会话；文件坏了或者大得离谱会直接报错，不做「尽力修复」。Open WebUI 那份只能读、不能反向导出。

### 一份归档装下整个库

`aqx` 一份文件能装多个会话：

- `/export --all` 把当前所有会话写进一份备份，换机或重装时一次搬回来；
- `/export --ids id1,id2` 只备份挑中的几个；
- 导入多会话归档时，界面先弹一个勾选面板（每行标题加条数，**默认全勾**），命令行用 `/import --pick 1,3`；
- 历史窗左栏底部的**「选择」**进入批量模式：勾选会话后可以一次导出成一份 `.aqx`，或一次删除（只确认一次）；命令行的删除写法是 `/rmconv id1 id2`。

只有 `aqx` 能一份装多个会话；另外三种格式是别人的规范，与 `--all` 一起用会直接报错，而不是悄悄只写一个。

### 角色卡（只读导入）

角色卡是角色扮演生态里现成的设定包（常见的 TavernCard）。本版把三种容器都读进来：PNG（卡数据藏在图片的文本块里）、纯 JSON、`.charx` 压缩包；导入后**原卡逐字节留档**，不认识的字段与资产也没有丢，只是暂时不生效。

- 命令面 `/character import|list|show|start|remove`，设置窗新增「角色」页（列表、头像、导入、删除、开始对话）；会话列表里的角色会话会显示头像。
- 开始对话时，卡的角色设定接在**你自己的默认人格之后**——你写的人设不会被卡悄悄替换。想让卡的 `system_prompt` 接管主提示，打开 `characters.prefer_system_prompt`；即使打开，平台与沙盒路径这类运行环境信息仍然保留。
- 示例对话作为一条**可被压缩挤掉**的上下文；开场白作为第一条回答，带序号可选第 N 条备用问候。
- 卡里标成「常驻」且没被作者禁用的世界书条目，会整段接进人格——不少卡把人设写在这些条目里，不注入就只剩个开场白。其余世界书条目仍要按关键词匹配才会生效，那是后续版本的事。
- 卡文本里的 `{{char}}` / `{{user}}` / `{{date}}` / `{{original}}` 会展开。
- **只读**：不改卡、不导出卡。卡里的正则与扩展脚本、表情/背景/语音资产保留但不执行；正文含 HTML 时界面按纯文本显示，导入时会提示。
- 同名卡不覆盖（要换版本先 `/character remove` 旧的）；删卡不影响已用过它的会话，只是头像回默认。导入不授予任何工具权限，卡里的文字就是文字。

### 输入框：参数提示与历史

- 打 `/` 开补全浮层；命令名后再敲一个空格，同一个浮层**切到参数提示**：能选的值（`on` / `off`、权限档、导出格式等）按 `Tab` 填入，`Shift+Tab` 反向轮换；自由文本参数只给一行说明，不替你填。
- `Enter` 始终是发送，不兼职补全；`Esc` 关掉浮层。
- 收起成单行时 `↑` / `↓` 翻**输入历史**：最近 50 条，相邻重复不记，翻到底就回到你翻之前打的草稿；展开成多行后方向键回到移动光标。

### 会话备份轮转

- 会话树每次保存前，先把上一份**能完整解析**的旧文件轮转为备份，默认保留 **3 代**（`<会话 id>.json.bak`、`.bak.1`、`.bak.2`…，最老的出局）。旧文件坏了不会挤掉更旧的可用备份；主文件缺失或损坏时按新到旧回退。
- 份数可在设置窗「常规」→「存储」→「备份代数」改（1–20，留空 = 默认 3），也可以直接改 `config.json` 的 `backup.keep`。**重启后生效**——会话树在启动时按它装配轮转。
- 删除会话时各代备份一并清掉，不会留下孤儿文件。

### 配置补强

- **provider 自定义请求头**：`model.providers[].headers` 给 `openai-chat` 协议的请求加头。与内置头同名时以你写的为准（鉴权头也可以覆盖），需要额外鉴权头或代理标记的服务因此能直接接。
- **提示词宏在非角色会话里也展开**：`{{user}}`、`{{date}}`（以及 `<USER>`）现在对默认人格与全部自定义模块生效，不再只有角色卡文本才替换。没有绑定角色时 `{{char}}` / `<BOT>` **原样保留**，不会悄悄替换成空串。

## 修掉的问题

- **导入格式认错**：识别只看文件开头 512 字节，长标题的 ChatGPT 导出认不出来，正文里提到「chat」的 OpenAI 文件又会被误判成另一种。现在读 64 KB 并按结构判断。
- **有损回执与实际不符**：ChatGPT 档明明丢了附件与节点元数据（模型、用量、思考签名）却只说丢了地址；空文本消息被跳过却不计数，显得「全都带过来了」；SillyTavern 的时间戳每往返一次漂一个时区；还无依据地宣称丢了工作区配置。
- **当前节点落在没有正文的消息上**（纯图片、纯思考）时整份文件被拒；现在沿父链落到最近的保留节点，并在回执里说明。
- **导出回执把「附件太大」说成「附件不在库里」**：两种原因分开报，一个能补字节、一个不能。
- **文件对话框**：Linux 上导入框因为过滤器沿用了 Windows 写法而列不出文件；保存框多问一次覆盖（实际仍会另存为 `-2`）；扩展名补点不正确；macOS 上标题里的引号会让脚本失效并被当成「用户取消」；连续点击会叠出两个对话框。
- **`/help` 与补全里的重复项**：被同名静态命令遮住的动态命令仍会列出来，点了也只会执行静态那条；命令名清单还可能被下游改写，下一次 `/help` 才暴露。两处都收掉了。
- **路径里有空格却没加引号**时只回一句「用法错误」；现在附一句怎么加引号，`/export` 与 `/import` 都覆盖。
- **导入其实已经成功、只是界面刷新失败**时，不再报成「导入失败」，而是说清「已导入并切换，但视图没能刷新」。
- **ChatGPT 导出的叶子节点缺空的 `children` 数组**：有些读方会把它当成不完整，现在补上。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行会生成配置指针与模板，先打开**配置引导窗**：填 provider 名、接口地址、密钥与模型名；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗「模型服务」页编辑；
4. 保存后重启即可对话；`/help` 查看全部命令。

**升级**：配置与会话都在 `~/.aquarius/`，本版磁盘格式向后兼容（旧会话缺的新字段按空处理），替换 exe 即可，不需要迁移。改动配置前建议备份该目录（也可在应用内用 profile 隔离试验）。

**卸载**：删除 exe 与 `~/.aquarius/` 目录。

## 已知限制

- Windows 为完整形态；Linux/macOS 可构建运行，但 GUI 为降级形态（无托盘、全局热键、半透明/羽化、原生右键菜单），**语音采集仅 Windows**。
- 角色卡只读：不能编辑或导出卡；世界书只注入「常驻」条目，按关键词检索、`order` 淘汰尚未实现；正则脚本、表情/背景/语音资产保留但不执行；卡正文里的 HTML 按纯文本显示。
- 会话导出里 Open WebUI 只能读、不能写；`chatgpt` / `openai` / `sillytavern` 是有损格式，`openai` 与 `sillytavern` 只带当前那条链。
- 本地 whisper 需要自备 ggml 模型文件，不随二进制分发；云端识别与合成需要联网，音频会发送给你配置的服务商，除非识别方式选了「本地 whisper」。
- 录音固定使用系统默认输入设备，默认 60 秒、上限 4 分钟；不支持唤醒词与自动断句。
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。
- Go 级进程内插件尚未开放；扩展能力目前走 MCP 与技能。
- 没有「工作区」概念：文件工具使用绝对路径或会话附件，不绑定当前目录。
- 字体字距有一处缺陷：`T` 之后相邻字母会少一点间距，根因在上游渲染库，本版仍未修。

## 校验

```text
aquarius.exe -version
Aquarius v0.3.0 (windows/amd64, go1.27.3)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。`SHA256SUMS.txt` 在构建机上生成：

```powershell
"$((Get-FileHash aquarius.exe -Algorithm SHA256).Hash.ToLower())  aquarius.exe" |
    Set-Content SHA256SUMS.txt -Encoding ascii
```
