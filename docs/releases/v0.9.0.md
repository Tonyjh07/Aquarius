# Aquarius v0.9.0
<!-- docs-sync: 2026-11-22 @ 27cd689 -->

第九个公开版本。这一版的主线是「换服务商与搬旧数据不再难受」：DeepSeek 的文件解析、语音、
整库导入、服务端读链接四条路径接通，端点能力改为声明制、不认的参数自动收敛不再手动排查；
加上一批会话管理能力——回收站、分叉、标签置顶、搜索、md/html 导出。界面侧补齐反馈与
浏览体验：Markdown 表格、Turn 过程折叠、规范化的右键菜单、`/doctor` 体检。会话树与配置文件
没有换范式，替换 exe 即可升级。

## 这个版本新增

### 会话回收站

- `/rmconv` 的删除不再直接丢文件：整份文件集（会话文件、备份、会话记忆）改名移进
  `<profile>/trash/`，删除时间就是主文件的改动时间；
- `/trash` 列出回收站、`/trash restore <id> ...` 还原回原 ID（撞上占用中的 ID 会拒绝）、
  `/trash empty` 清空（二次确认）；
- 主文件改动超过 30 天的条目在下次启动时清掉并留一行日志；30 天写死，不提供配置。

### `/fork`：从任意节点分出新会话

- `/fork <节点id> [标题]` 把那个节点及其整棵子树摘成新会话：结构与兄弟顺序原样保留，
  新会话的开头就落在分叉节点上；
- 节点 ID 全部重新生成；「修订自」等溯源信息不跨会话复制；附件引用原样带上（字节共享，
  不会重复占空间）；标题缺省沿用原会话；
- 保存即切换并清屏回放，原会话一字不动。会话根不能摘。

### 会话标签与置顶

- `/tag <会话> [名...]` 加标签、`/tag <会话> --rm <名>` 删标签，去重保序；
- `/pin` 切换置顶；`/list --tag <名>...` 按标签过滤（多个标签取交集）；
- 列表里置顶的会话排在前面（组内仍按更新时间），带 `▲` 标记；打标签与置顶不改更新时间；
- 会话分叉不带走源会话的标签与置顶。

### 导出为 Markdown / HTML

- `/export --format md` 与 `--format html`：同一份摊平内容的另一种呈现——`md` 正文原样、
  可整份粘进新对话，角色标题跟随界面语言；`html` 包成单文件（内联样式、目录、时间戳），
  双击浏览器就能看；
- 导出视角与上一版的互通格式同源：同一条 Head 路径、同样的丢弃计数与旁支注记；
- 不做 Markdown 渲染、也不进导入识别——这是给人看的，不是新的互通格式。

### DeepSeek 整库导入

- `/import` 现在认 DeepSeek 官方导出的整库 ZIP：路径级识别、流式解包，
  `--all` 全导、`--pick` 按清单挑选，每 100 条一批；
- 导入记录写在 `import-sources` sidecar 里，同一份导出重复导入时按更新时间去重；
- 附件默认一起带（`--no-files` 可关）；搜索轨迹丢弃并计数、非图片文件丢弃；
- 不建角色卡首节点，导入的就是普通会话。

### 会话搜索

- `/search <关键词>` 跨会话搜标题与正文：子串匹配，`--regex` 走正则，`--tag` 按标签过滤
  （交集），命中上限 100 行；
- 图形界面的左栏与导入勾选面板各带一个过滤框，随打随筛；
- 没有全文索引——每次都现搜，百会话量级在毫秒级。

### 文件交给服务端解析（DeepSeek）

- 声明了 `files` 能力的端点上，结构化文档（PDF、Word、Excel 等）先上传到 DeepSeek Files API，
  请求里用 `file_id` 引用、由服务端解析；文档内嵌的本地提取文本照旧带上，能力位不生效时
  请求体与从前一字节不差；
- `files.purpose` 选解析档：`text_recognition`（缺省，只提文字）或 `rich_layout_recognition`
  （图表一起交，更贵更慢）；空串 = 关闭这条路径；
- `files.ttl_seconds` 控制服务端保留时长（缺省 0 = 永久保留）。隐私口径：文件与解析结果都
  落在服务端、账号级共享，在意就设短 ttl 或关掉。

### DeepSeek 语音后端

- `audio.asr.kind: "deepseek"`：识别走 `/v1/tools/asr`，无需 model、无语种参数（21 种语言
  自动识别）；单段上限 120 秒 / 8 MiB，选中后录音硬顶自动降到 120 秒；
- `audio.tts.kind: "deepseek"`：合成走 `/v1/tools/tts`，音色只认 `stella` / `tide`（别的名字
  启动报错）；风格控制不认（配了会警告「已忽略」）；超 10000 计费字符明确报错、不切片拼接；
- 端点与密钥借默认 provider，不再单独配置。

### 时间感知

- `clock.mode` 三档：`off` = 不注入（请求体与从前一字节不差）；`live`（缺省）= 每次请求
  末尾带一条时间戳 system 消息（日期、时区偏移、星期、本 Turn 已跑多久、上一批工具耗时）；
  `tree` = 之上再给历史 user 消息补各自时刻（不落盘）；
- 会话内用 `/clock off|live|tree` 切换，不写回配置文件。

### `/context` 前缀稳定性对比

- 概览末尾新增一行「与上一轮相比前 N 字符未变（x%）」——提示词缓存的命中面一眼可见；
- 对比跳过时间注入段（时间每轮都变，不算漂移）；跨会话与首次请求不出这一行。

### 脚本化工具调用（实验性）

- `tools.mode: "ptc"` 把工具调用搬进脚本：模型写一段 Starlark（进程内解释器，无 cgo），
  一个脚本里串多次工具调用，中间结果不出解释器、不占上下文；`tools.mode: "native"`（缺省）
  与从前一致；
- `run_code` 是普通工具，脚本内的调用同样过权限矩阵；需要确认的调用在同一脚本内去重
  （同一工具同一参数只问一次），配额与限额在 `tools.ptc` 四个键里调；
- `/code` 看最近一次脚本的只读留档；
- 实验性：开关名字和默认限额都可能在后续版本调整，介意的话留在 `native`。

### 端点能力声明与自动收敛

- `model.providers[]` 新增三个键：`family`（端点家族，只决定能力缺省值，可填 `deepseek`；
  缺省按 `base_url` 的 host 猜）、`server_caps`（该端点认的服务端能力：`title` / `read_url` /
  `files` / `web_search` / `safety`）、`unsupported_server_caps`（实测不认的能力，自动记录）；
- 某项能力发出去收到 400，自动记进 `unsupported_server_caps` 并不再发——中转网关做了字段
  白名单时，这项自己会收敛，不需要用户知道网关透传了什么；
- 词表外的家族名与能力名启动即报，写错一个词不会静默把能力全关。

### 用量分项

- `/usage` 与 `/cost` 新增缓存读、缓存写、思考、审核四个分项（端点没报就整行省略）；
- 输入 token 一律折成总输入（含缓存两段），缓存命中率在四家协议上同一算法；
- 分项落盘随会话走；只记数不计费，金额仍按全价折算。

### 会话标题由模型顺带生成

- `title.enabled`（缺省开）：首轮请求带上标题生成项，标题从收流末尾读回，一次给全；
- 只对声明了 `title` 能力的端点生效；端点不认时自动记进 `unsupported_server_caps`，
  不需要手动关；
- `/title` 起过的名字永不被覆盖；拿不到标题时静默回落到首条消息摘录，不是错误。

### 服务端读链接（DeepSeek）

- `web_fetch` 只抓到壳子（正文全在 JS 里）且地址来自本轮用户消息时，那一轮自动切换成
  服务端的 `deepseek_read_url`：只声明服务端阅读工具、不带本地工具（协议里两类不能共存）；
- 服务端返回的阅读块原文整块存进会话并逐轮回传（协议要求），正文加密在块内、客户端解不开
  也改不得；
- 用过服务端阅读链接的回复不能续写（`/respond` 会当场拒绝）；只对 Messages 协议生效。

### `/doctor`：一次体检

- 一条命令查七件能出问题的事：配置解析、密钥库、会话文件、MCP 声明状态、`logs/` 与
  `exports/` 占用、磁盘余量；每项三态（正常 / 注意 / 异常）加一句修法；
- 全绿只回一行；有问题时七项全列。不发模型请求、不连 MCP、不写盘；
- 命令行 `aquarius.exe -doctor` 走同一份检查（无界面宿主，MCP 一项改校验声明；有异常项时
  退出码 1）——打不开界面时也能用。

### 设置窗「日志」页

- 列出按天切分的运行日志，点开看只读末尾（64 KiB 起、上限 1 MiB）；一键打开日志目录；
- 只读，本页不写盘、不跟随写入。

### Markdown 表格渲染

- 对话里的 Markdown 表格按网格渲染：表头加粗、横竖细线、列宽按内容分配、单元格各自可选、
  复制按单元格逐行——不再整段按原文呈现；
- 其余 Markdown 语法维持原样（仍只渲染有限子集）。

### 主窗反馈层

- 报错与没有归属的命令输出收进命令折叠条：条目带严重度、头行按构成计数、有错误的头行转红；
- 运行痕迹不再借用助手气泡的底板——气泡只承载对话内容。

### 右键菜单规范化

- 气泡与图节点的右键菜单按使用频率分层：高频项在顶层，编辑变体与查看类进「更多」，
  图侧的节点操作与删除进「节点」「危险」子菜单；logo 菜单重排（置顶与无人值守相邻成组）；
- 顺手修掉一个 bug：刚发出的消息右键偶尔没反应（命中判定从抬起帧改到按下消费帧）；
- 托盘菜单不动。

### Turn 过程折叠

- 最终回答定稿后，本轮的思考块与工具条折成一行摘要「工作 x 秒，调用了 x 个工具」，
  点击展开铺回原块；纯思考轮维持原有的单块折叠；
- 折叠只在显示层：分叉、复制、回放的行为与从前一致。

## 行为变更

- **删除的会话先进回收站**（30 天后启动时清掉），不是直接消失。要立刻腾空间用 `/trash empty`。
- **时间感知默认打开**（`clock.mode` 键缺失 = `live`）：每次请求会多一条时间戳 system 消息。
  不想要的话写 `clock.mode: "off"`，请求体与上一版一字节不差。
- **会话标题默认由模型生成**（`title.enabled` 缺省开，且端点要认 `title` 能力）。首条消息
  摘录作标题的旧行为仍是拿不到标题时的回落。
- **DeepSeek 家族的端点默认认为五项服务端能力全开**（按 host 猜认出时）；自建网关猜不出来
  就一项都不发，需要显式写 `server_caps`。
- **命令输出与报错换了承载**：收进命令折叠条、有错误的头行转红，不再出现在助手气泡里。
- **右键菜单重排**：常用的项直接在顶层，编辑与查看类进「更多」子菜单——肌肉记忆要重新
  找一下位置。
- **多一个新工具与呈现模式**：`tools.mode: "ptc"`（实验性）与 `run_code` 工具；缺省 `native`
  不受影响。
- **第三方组件清单多一个**：`go.starlark.net`（BSD-3-Clause），见
  [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md)。

## 修掉的问题

- 刚发出的消息右键偶尔没反应（命中判定改在按下消费帧解析并按块序找回）；
- Markdown 表格在对话里整段按原文呈现，读不出结构；
- 端点不认的服务端参数逐个手动排查，现在收到 400 自动记名、此后不再发；
- 输入 token 数在 Anthropic 协议上不含缓存两段，缓存命中率与别家对不上（已统一折成总输入）。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行先出五步引导：选界面语言、阅读并同意条款、填模型接入（或点「稍后配置」）、
   看一遍基本用法、确认保存；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗编辑；
4. `/help` 查看全部命令，`/doctor` 体检一次配置。

**升级**：配置与会话都在 `~/.aquarius/`，本版磁盘格式向后兼容，替换 exe 即可，不需要迁移。
`clock` / `files` / `title` / `server_caps` 几段不写也有缺省值；升级后多一个目录：
`profiles/<name>/trash/`（只在删过会话后产生）。

**卸载**：删除 exe 与 `~/.aquarius/` 目录。

## 已知限制

- **脚本化工具调用是实验性的**：`tools.mode: "ptc"` 与 `tools.ptc` 的键名、缺省限额都可能
  在后续版本调整；解释器在进程内执行，权限矩阵照常生效，但脚本一次串联多步的失败排查
  比 native 模式难——`/code` 的留档是唯一的回看口；
- **DeepSeek 识别单段 120 秒 / 8 MiB**：超限明确报错、不静默切片；长录音先手动分段；
- **合成音色只有两个**（`stella` / `tide`），风格控制不生效（启动警告「已忽略」）；
- **文件解析落在服务端**：文件与解析结果账号级共享、缺省永久保留，在意就设
  `files.ttl_seconds` 或 `files.purpose: ""` 关掉；
- **服务端读链接的回复不能续写**，且只对 Messages 协议生效；本地 `web_fetch` 仍是默认路径，
  只在抓到壳子时才切换；
- **导入不是全保真**：DeepSeek 导入丢搜索轨迹（有计数）、丢非图片附件、不建角色卡首节点；
  导入前先在原平台核对想保留的东西；
- **`/search` 是现搜**：没有全文索引，万会话量级会明显变慢；
- **表格只认 GFM 语法**，非 GFM 的表格写法仍按原文呈现；
- 沿用上一版：Linux/macOS 可构建运行，但 GUI 为降级形态（无托盘、全局热键、半透明羽化与
  原生右键菜单），语音采集仅 Windows；字体字距在 `T` 之后偏窄，根因在上游渲染库；
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。

## 校验

```text
aquarius.exe -version
Aquarius v0.9.0 (windows/amd64, go1.27.4)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。
