# Aquarius v0.6.0
<!-- docs-sync: 2026-11-08 @ 021fcfe -->

第六个公开版本。这一版把外部代理从「手写配置文件」搬进设置窗：增删改、试连接都在界面里完成；
被转交的代理读写文件与执行命令时，先经过 Aquarius，可以逐条审。另有两处行为变更——`-yes`
开关移除，界面文案按同一套中文写法复审一遍。聊天、权限模型与会话树没有换范式；磁盘上的配置与
会话格式向后兼容，替换 exe 即可升级。

## 这个版本新增

### 外部代理：在设置窗里配

- 一行一个列出代理：名字、可用性（现探 `PATH`）、缺省标记，不可用的写明原因；
- **新增 / 改名 / 删除**：底部「新增代理」填名字与命令行即可加一条，删除要再点一次确认。
  重名、缺名、命令行空、引号没闭合都当场拦下——这些错误会让下次启动直接报错；
- **按字段编辑**：点「编辑」展开命令、参数（一行一个）、环境变量（一行一个 `KEY=VALUE`，
  值可写 `secret:<名>`）、工作目录。保存写回配置，重启生效；
- **测试连接**：起一次进程做握手，回显对方的名字、版本、协议版本、登录方式、申报的能力，
  以及当前模型与可选个数。失败分开说「命令不在 `PATH` 上」「起不了进程」「握手失败」，
  最后一种还带对方自己的错误输出尾巴；
- **重新检测**：改完 `PATH` 或刚装好那个程序，点一次重探，不用重启。

### 文件访问经过 Aquarius

代理愿意走协议时，读写先落到 Aquarius 手里：范围内的直接做，范围外的读按次数问你
（缺省 8 次，同一文件只问一次），范围外的写每次都问。范围 = 这次转交的工作目录，加上你派活
时批准过的额外目录，不写进配置。

写版本控制钩子、编辑器与代理设置、MCP 配置这几类文件之前，单独问一次。

报告分成三段：**经 Aquarius 之手写下的文件**、**代理自己报过的改动**、**问过才读到的范围外
文件**。前两段不合并——一份是我们经手的，一份是代理自称的，混在一起就分不出哪条能当事实。

### 命令也经过 Aquarius

- 申报终端能力之后，代理可以把命令交出来：进程由 Aquarius 起，确认框里显示命令行、目录与
  环境变量。同意一次等于允许这条命令跑完——这条命令能 `cd`、能起子进程；
- 每条命令问一次，一次转交问满 8 次之后一律拒并记进报告（`delegate.terminal_ask_max` 可调）；
- 报告只列命令与退出码，命令输出不进正文；失败的那条附输出末尾一小段；
- 不想让代理跑命令，配置里写 `delegate.terminal: false`：五个终端方法一律回「方法不存在」，
  代理只能自己起 shell，而那条路看不见。

### 转交时定模型

- `delegate.agents[].options` 给这个代理的会话定下选项：模型、思考档位、模式；
- 填的是代理广告的标识，不是代理界面上显示的名字。kimi 显示 `trae/deepseek-v4.1-flash`，
  能填的是 `gw/deepseek-v4.1-flash`；opencode 显示 `deepseek/DeepSeek V4 Flash`，能填的是
  `deepseek/deepseek-v4-flash`；
- 不知道怎么填就点「测试连接」：探测会建一次会话，把当前模型与可选个数摊在回执里；
- 设不上就整次转交失败，并列出可填的值，不会静默换成默认模型接着跑。报告恒写实际模型，
  没配过的标「对方默认」。

### 界面文案

按同一套中文写法复审了全部界面文案：删掉漏进界面的内部标记与 Markdown 星号，行话换成用户
能读的话（「未接线」→「不可用」、「落盘」→「保存」），同一动作统一用一个词，报错与空状态
补上接下来能做什么。逐条结论与保留理由见 [stc/review.md](../stc/review.md)。

## 行为变更

- **`-yes` 开关移除**。这个开关把两件事捆在一起：没人在（提问一律按「离开」回答）与一律放行
  （所有确认都答「是」）。现在前者归「无人值守」，后者归权限档 `full-access`。原来靠这个开关跑
  脚本的，改成写配置；
- **插件授权跟随无人值守**：开着无人值守时，新插件与新申请的能力**不启动**，只记一条日志，
  下次交互启动再问。以前 `-yes` 会连信任门一起放行；
- **用户自己敲的命令确认**（`/rm`、`/rmconv` 这类）不再有任何开关能绕过。

## 修掉的问题

- 命令确认里命令行折成三行后，紧接的「目录：」与命令读成一整块，看不出命令到哪儿结束；
  两者之间补了空行。窄窗口下同样分得清；
- 命令行看不出参数边界（`--flag a b` 与 `--flag "a b"` 一个样），含空白的参数现在加引号；
  Windows 路径的反斜杠也不再双写成 `E:\\Aquarius`；
- 会话选项没设上时，报告仍写着「已配置」；现在按「现值与配置值一致」判定；
- 「条款正文载入失败」原来错成「正文档载入失败」；联网抓取的回落变量补全为
  `AQUARIUS_DEEPSEEK_FETCH_API_KEY`（原文只写到 `_FETCH_`）。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行先出五步引导：选界面语言、阅读并同意条款、填模型接入（或点「稍后配置」）、
   看一遍基本用法、确认保存；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗
   「模型服务」页编辑；
4. `/help` 查看全部命令。

**升级**：配置与会话都在 `~/.aquarius/`，本版磁盘格式向后兼容，替换 exe 即可，不需要迁移。
改动配置前建议备份该目录（也可在应用内用 profile 隔离试验）。`-yes` 已移除，用到这个开关的启动
脚本要改。

**卸载**：删除 exe 与 `~/.aquarius/` 目录。

## 已知限制

- **申报不等于沙箱**：代理自己起 shell 之后，读写与命令都不经过 Aquarius。kimi-code 会把
  命令交出来，opencode 不读这两项能力——同一件任务，给前者能逐条审，给后者只能事后看代理
  报了什么；
- **越界读不做门禁**：代理自己就有 shell，读不经过我们照样能读，为读弹框拦不住东西；
- `options` 里写 `"mode": "yolo"` 这类全自动模式时，前面那些确认框可能根本不会弹——
  能让代理全自动，和能逐条审，是两件互斥的事；
- Windows 上 `.cmd` / `.bat` 形状的命令（`npm` → `npm.cmd`）起不来，错误会如实回给代理。
  不经解释器是有意的：闸门要的正是这一层；
- 沿用上一版：Linux/macOS 可构建运行，但 GUI 为降级形态（无托盘、全局热键、半透明羽化与
  原生右键菜单），语音采集仅 Windows；字体字距在 `T` 之后偏窄，根因在上游渲染库；
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。

## 校验

```text
aquarius.exe -version
Aquarius v0.6.0 (windows/amd64, go1.27.3)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。
