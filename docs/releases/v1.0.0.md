# Aquarius v1.0.0
<!-- docs-sync: 2026-11-28 @ c82fec4 -->

第一个正式版。这一版的主线是 **Tier-1 Go 插件系统**：插件契约冻结成稳定模块，本体内置
装载器与 `/plugin` 管理面，首个样例插件（间隔重复记忆）随版交付；六个能力供给面全部接通
消费侧——插件可以提供模型、摄取、输出、语音与密钥兜底。界面侧补了设置窗的插件页与工具页、
删除数据目录的安全入口，以及一批动效与观感修正。会话树与配置文件没有换范式，替换 exe
即可升级。

## 这个版本新增

### Tier-1 Go 插件（主线）

- **插件契约已冻结**（`pluginapi/v1`）：独立 Go 模块、零第三方依赖、只增不改；对插件作者
  的完整说明见 [plugin-guide.md](../plugin-guide.md)。插件与内核各编各的二进制，通过
  稳定值类型与防腐层对接，升级内核不要求重编插件。
- **`/plugin` 管理面**：list / enable / disable 状态写回配置、重启自动恢复；`/plugin view`
  打开插件自带的面板（GUI 渲染组件树，TUI 渲染只读文本）。
- **六个供给面全部接线**，语义各不相同：
  - **模型**：插件模型出现在 `/model` 清单里，按名路由；截断/审计/重试/降级链照常生效；
  - **记忆**：插件接管期间内置 `memory_*` 四工具与 `/memory` 退出、内置记忆只读，停用还原；
  - **语音**：转写/合成启用即接管、停用还原内置选型；同类多插件第一个赢；
  - **摄取**：插件只接内置不认的输入类型，内置优先；
  - **输出**：插件输出器按名进扇出，失败只记日志；
  - **密钥**：插件是读链的最后一档兜底（本机密钥库 → 环境变量 → 插件），写侧不动。
- **插件可申报 UI**：独立设置页、管理面板、自有窗口与随包 sidecar 文件。
- **首个样例插件**：间隔重复记忆（独立仓库 `aq-memory-plugin`），覆盖工具面、记忆接管、
  面板与命令面四种形态，也是契约与装载器的活文档。
- **外部私有插件**：上游保留中性的构建期接入口（`cmd/aquarius/pluginext.go`），用
  `go run ./cmd/aqbuild` 注入编译，上游产物零痕迹。

### 设置窗

- **插件页**：插件清单、启停与说明，只读展示不含配置编辑；
- **工具页**：工具模式（native / PTC）、决策模式表单、内置工具分组开关——这几项此前只能
  手写配置；
- **删除整个数据目录**：设置页新增危险入口，展开后要输入 `DELETE` 确认才生效，退出程序时
  才真正删除（运行中的文件不会被占用阻断）。要备份先看 [storage.md](../storage.md)；
- **危险按钮统一实底红底白字**（删除、确认删除等），不再与普通按钮混淆。

### 界面观感与交互

- 权限确认提示收进一条可展开的折叠条，排队等待的提示不再互相覆盖；
- Turn 过程折叠/展开带动画，转写尾部滚动带缓动，新增「回到底部」悬浮按钮；
- 助手输出的 Markdown 源码可从查看窗复制；
- 字体集合补符号回退档，缺字形不再直接落豆腐块。

## 行为变更

- **多两个数据目录**：`profiles/<name>/plugin-data/<插件>/`（插件持久数据）与
  `plugin-tmp/<插件>/`（临时目录，每次启动插件实例前清空）。不装插件不会产生。
- **启用记忆类插件会改变工具面**：`memory_*` 四工具与 `/memory` 让位给插件、内置记忆转
  只读，停用插件即还原。给了内置记忆就别同时启用两个记忆插件（第二个会被拒绝）。
- **密钥读链多一档**：本机密钥库与环境变量都没有的引用，会问到已启用的密钥类插件。
- **危险按钮外观变化**：删除类操作是实底红底白字，深浅两套主题都过对比度校验。
- **MCP 工具的风险默认按来源取**：MCP server 声明的提示在渲染结果首行注明来源；
  服务端未声明的风险档走保守默认。

## 修掉的问题

- 本地精确计数器（tokenizer）的预切分正则加超时上限、计数全程可取消——模型可控的长文本
  不会再把计数卡死，超时自动回落通用估算；
- `think` 工具的空白内容在运行时报失败，不再往树里留空调用；
- 压缩/摘要生成流在转写里标注「正在生成摘要」，不再混同普通回答；
- `/usage` 与事实卡的「上轮实测」改「最近实测」（该值是最近一次完成请求的实测，不一定是
  上一轮问答）；
- 审计文件打不开时降级为提示并继续运行，不再连带启动失败；
- `run_code` 脚本里带图片的工具调用，图片引用正确带回会话；
- 并发的权限确认请求排队逐条询问，不再互相覆盖。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行先出五步引导：选界面语言、阅读并同意条款、填模型接入（或点「稍后配置」）、
   看一遍基本用法、确认保存；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗编辑；
4. `/help` 查看全部命令，`/doctor` 体检一次配置。

**升级**：配置与会话都在 `~/.aquarius/`，磁盘格式向后兼容，替换 exe 即可，不需要迁移。
本版新增的目录（`plugin-data/`、`plugin-tmp/`）只在装了插件后产生；插件契约已冻结，
v1 系列升级不要求重编插件（承诺见 [stability.md](../stability.md)）。

**卸载**：删除 exe 与 `~/.aquarius/` 目录（或在设置窗用「删除数据」入口）。

## 已知限制

- **插件生态刚起步**：随版交付的样例只有间隔重复记忆一个；模型/语音类插件的消费语义已
  接线并测试，但还没有真插件长期实机验证；
- **插件面板在 TUI 是只读文本**：组件树渲染只在 GUI 生效；
- **PTC（程序化工具调用）与模型辅助决策仍是实验性**：键名与缺省值随版本调整，
  见 [stability.md](../stability.md)；
- 沿用上一版：DeepSeek 识别单段 120 秒 / 8 MiB；合成音色两个、风格控制不生效；文件解析
  落在服务端（账号级共享，在意就设 TTL）；服务端读链接的回复不能续写；导入不是全保真；
  Linux/macOS 可构建运行但 GUI 为降级形态，语音采集仅 Windows；字体字距在 `T` 之后偏窄
  （根因在上游渲染库）；
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。

## 校验

```text
aquarius.exe -version
Aquarius v1.0.0 (windows/amd64, go1.27.4)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。
