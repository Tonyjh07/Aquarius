# Aquarius v0.8.0
<!-- docs-sync: 2026-11-17 @ 19a3e76f -->

第八个公开版本。这一版回答两类问题：模型到底收到了什么、钱花在哪儿了；以及那些「重启就丢、
崩了没痕迹」的地方。新增五个查看口——装配好的上下文、模型的原始返回、审计日志、跨会话花费、
一次请求的诊断包；输入历史与崩溃报告改为写入磁盘；语音输入改成按说话分段。会话树与配置文件
没有换范式，替换 exe 即可升级。

## 这个版本新增

### 语音按说话分段

- 录音不再攒完整段再返回，改为每 32 毫秒推一帧给内置的语音检测（Silero VAD，纯 Go，
  无 cgo、无外部模型文件）；
- 停顿超过 `min_silence_ms`（默认 100 毫秒）就切一段，逐段转写、按说话顺序用换行接起来；
  一次按键仍是一条消息；
- 一句话都没说时什么都不产生：不建附件、不发起转写、不提交消息；
- 短于 `min_speech_ms`（默认 250 毫秒）的响动丢弃，挡住咳嗽与键盘声；
- 关掉 `audio.vad.enabled` 退回整段录音，行为与上一版一致。

### `/context`：看即将发出的上下文

- 无参给分块账：每条消息、每段是什么、各占多少 token，含工具声明；带编号看那条消息的全文；
- `last` 看上一轮**实际发出**的那份（含自动压缩之后的形态）；`full` 整份写进导出目录，
  图形界面同时打开只读次窗；
- 标签由装配函数在追加处记下，正文取自已装配好的请求；没有另写一套「照规则再拼一遍」的
  展示逻辑；
- 只读：不写入会话树、不进日志、不改会话。

### `/raw`：看模型的原始返回

- 无参给最近一次的概览：协议、状态码、收流耗时、首字节、实收字节、结束原因，加一份帧目录
  （每帧字节数与首行摘要）；带帧号看那一帧的原文；
- 采的是响应体字节，解析代码一行未改；空行、`event:` 行、注释行、`[DONE]` 都保留；
- 结束原因分四种：收到结束标记、连接关闭（无标记）、调用方中断、收流出错；
- `-k` 往回数第 k 次请求，一轮里每次工具循环各算一次，只留最近 4 次；
- 不含请求头，URL 查询串只留键名；留档只在内存，单次上限 2 MiB，超出标「已截断」。

### `/audit`：读审计日志

- `/audit [-n 行数] [--tool 工具名]`，无参给最近 20 行：时间、种类（`llm` / `tool` /
  `policy` / `decide`）、名字、耗时、成败，另附该行的要点；
- `--tool` 按全名精确匹配，不区分大小写；`mcp:<server>:<tool>` 用全名过滤；
- 不显示参数内容：审计行本来就不记参数，这个视图也不新增字段；
- 坏行跳过，文件不存在按空处理；时间转成本地时区显示。

### `/cost`：跨会话看用量与花费

- `session` 或空参：当前会话的轮数、输入输出 token 与估算费用，与 `/usage` 同源，数字必然一致；
- `model`：按模型分组，跨全部会话，含已放弃的分支——那些分支也真花过钱；
- `day`：按天分组，只看最近 30 天内改过的会话文件；
- 数字全部来自会话树每个回答节点已有的用量，不另建台账；没有声明单价的模型只出 token 并写
  「未折算」。

### `/diag`：把一次请求的三份事实打成一份

- 一份文本写进导出目录：上下文的分块账、这一轮的审计行、最近一次的原始返回，开头写版本、
  平台与生成时间；回执给路径与大小，图形界面同时打开只读次窗；
- 三节共用**一个锚点**（上下文交付时刻），审计行取锚点前 5 秒到收流结束再加 2 秒的窗口，
  三个时间都印在文件里；
- 窗口不放大到整轮：宁可漏掉窗口外的审计行，也要让「三节取自同一次请求」经得起逐行核对；
- 不含密钥；审计一节取不到也照发，写「窗口内没有」；
- 头部写明含会话正文，转发前自己过一遍。

### 崩溃留下报告

- 顶层 panic 写 `<profile>/logs/crash-<ts>.txt`：panic 值、时间、版本、平台、Go 版本与栈；
- 退出码 2，与启动失败的 1 分开；
- 写盘失败不改退出码，另给一句「报告没写成」与原因；
- 下次启动提示一次，同一份不重复提示；历次报告留在目录里，不自动删除。

### 输入历史写进磁盘

- 一份 `<profile>/input_history.jsonl`，GUI 与 TUI 共用；重启后按 ↑ 还能翻到上次输入；
- 一行一个 JSON 字符串：多行输入算一条，行数与条数才对得上；
- 追加写，文件过 400 行时压实到最后 50 条；
- 读时去相邻重复，只留最近 50 条；坏行跳过，文件不可读写时退化为内存历史，不挡启动。

### `file_grep`：按内容搜索不再弹确认

- 新增 Safe 只读工具，返回 `路径:行号:内容`，行号从 1 起，与 `file_read` 的前缀规则一致；
- `query` 缺省按字面量，`regex=true` 才走 RE2；`ignore_case` 折叠大小写；
- 默认跳过 `.git` / `.hg` / `.svn` / `node_modules`、二进制文件与超过 1 MiB 的文件，
  跳过的文件数在结果里报出；
- 命中 100 条或扫描 5000 个文件即停，并说明触了哪一道；每行截断到 240 字符。

### 密钥库「收进存量明文」入口回来

- 设置窗「密钥库」页一行说明加一个按钮，回执写在同行右侧；
- 一次扫描 provider 密钥池、`audio.asr`、`audio.tts`、`decide` 与联网两组提供商的 `key`，
  逐个写进密钥库，config 改成 `secret:<名>` 引用，值不变；
- 已是 `secret:` 的不重复处理，库里已有的条目一律不动；
- 空值不补条目；两处派生出同一个键名时，第二条报失败并点名位置，不静默覆盖。

## 行为变更

- **语音输入默认按说话分段**。要回到整段录音，在设置窗「语音」页关掉，或写
  `audio.vad.enabled=false`。
- **`file_grep` 不需要确认**。这是放宽：路径仍按权限矩阵的读范围判定，越界照问。
- **多一个明文文件**：`input_history.jsonl` 存着打过的指令，可能含粘贴的私密内容，
  与会话文件同等敏感。
- **崩溃退出码固定为 2**。脚本据此区分「配置写错了」（1）与「程序自己崩了」（2）。

## 修掉的问题

- 任务报告在推进中的一轮里到达时，那一轮可能被静默丢掉：轮末只写入、不触发，随后唤醒来时
  队列已空。机器越快越容易撞上，Linux 上稳定复现；
- 权限硬名单在非 Windows 宿主上不认反斜杠，`C:\proj\.git\hooks` 曾被当成一个文件名放过；
- 附件 chip 遇到另一平台的路径时把整条路径当成文件名显示；
- 界面文案与代码注释里的一批行话（「落地」「落码」「落盘」「口径」等）改成直白说法，
  中英两份同步；
- 工程笔记里指代不明的「它」逐段换成具体的名称。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行先出五步引导：选界面语言、阅读并同意条款、填模型接入（或点「稍后配置」）、
   看一遍基本用法、确认保存；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗编辑；
4. `/help` 查看全部命令。

**升级**：配置与会话都在 `~/.aquarius/`，本版磁盘格式向后兼容，替换 exe 即可，不需要迁移。
`audio.vad` 一段不写也有默认值（分段开着）。升级后多两个文件：
`profiles/<name>/input_history.jsonl`（输入历史）与 `logs/crash-*.txt`（只在崩溃时产生）。

**卸载**：删除 exe 与 `~/.aquarius/` 目录。

## 已知限制

- **语音分段的阈值没有标定过**。`threshold` 与 `min_silence_ms` 沿用上游缺省值，嘈杂环境
  可能把噪声切成碎片；退路只有关掉分段；
- **`go-silerovad` 没有上游 tag**，依赖钉的是提交号；
- **`/raw` 只在内存**：留最近 4 次、单次 2 MiB，重启即空；要看更早的请求得重新复现；
- **`/diag` 只讲最近一次请求**，没有参数可选；审计行的时间解析不了就会被丢掉——这是刻意的，
  猜错一侧会混进别的请求；
- **`/cost` 的单价完全取决于配置**：错价会直接体现在账上；`model` 与 `day` 要读多个会话文件，
  百会话量级首次统计要一两秒；
- **`file_grep` 的上限只保证不失控，不保证快**：巨大目录仍会耗时；
- **崩溃报告只写进程状态**，不含会话正文；要不要发出去由你判断。报告落在用户目录，
  程序不会自动上传；
- 沿用上一版：Linux/macOS 可构建运行，但 GUI 为降级形态（无托盘、全局热键、半透明羽化与
  原生右键菜单），语音采集仅 Windows；字体字距在 `T` 之后偏窄，根因在上游渲染库；
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。

## 校验

```text
aquarius.exe -version
Aquarius v0.8.0 (windows/amd64, go1.27.4)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。
