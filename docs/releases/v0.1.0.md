# Aquarius v0.1.0
<!-- docs-sync: 2026-10-21 @ b70993b -->

首个公开发布：一个面向个人的极简 AI 助手。单二进制、对话优先、数据全部留在本机，模型与工具都可替换。

## 这个版本能做什么

- **会话树**：消息创建后不可变；「修改」即从该条分叉出新节点，随时回溯、分支、对比。
- **上下文压缩**：手动 `/compact`、超阈值自动压缩、模型经工具自触发，三轨并存。
- **多模态输入**：文件与剪贴板摄取，pdf/docx/xlsx/html 自动转文本；图片直接进对话。
- **屏幕捕获**：内置工具让模型列窗口、抓全屏，或抓**被其他窗口遮挡**的窗口（Windows）。
- **语音输入与播报**（Windows）：
  - 输入框为空时，右侧圆钮变成麦克风：点一下开始录音、再点一下结束，转写文字**回填输入框**，
    不会替你按回车；有输入时仍是发送键，录音中变成停止键。
  - `/mic` 在 TUI/repl 里完成同样的「录 → 转写 → 提交」。
  - 开启「朗读回答」后，回答提交即整段合成并播放；停止键取消本轮时同时静音。
  - 设置窗的**「语音」页**：识别/合成各自的服务与模型、录音语种、音色、音色描述、
    风格指令与风格标签，并带**试听**——音色和风格不用先保存就能试。服务、模型与录音语种
    保存后重启生效；音色、描述与风格保存后对之后的朗读立即生效。
- **模型与提供商**：多 provider（OpenAI chat / responses / Anthropic 协议）、密钥池与自动轮换、
  有序降级链、模型启用位、能力与连通性探测；端点与模型改动保存后重启生效。
- **工具与扩展**：文件读写/编辑、终端执行、后台任务、记忆文档；MCP 支持 stdio 与 streamable HTTP，
  外部 server 与内置工具同权，带逐能力授权。
- **三种界面**：Gio 悬浮球 GUI（默认，托盘常驻、全局热键、深浅主题跟随）、bubbletea TUI、行式 repl。
- **本地优先**：数据全部在 `~/.aquarius/`，profile 整目录隔离；密钥优先存本机加密密钥库，
  config 里只留 `secret:<名>` 引用。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行会生成配置指针与模板，并打开欢迎窗引导填写模型服务；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗
   「模型服务」页编辑：填 `base_url`、模型名与密钥。密钥推荐用环境变量
   `AQUARIUS_OPENAI_KEY`，或在设置窗直接填（会自动转入本机加密密钥库，config 只留引用）；
4. 保存后重启即可对话；`/help` 查看全部命令。

**升级**：配置与会话都在 `~/.aquarius/`，替换 exe 即可。改动配置前建议备份该目录
（也可在应用内用 profile 隔离试验）。

**卸载**：删除 exe 与 `~/.aquarius/` 目录。

## 已知限制

- Windows 为完整形态；Linux/macOS 可构建运行，但 GUI 为降级形态（无托盘、全局热键、
  半透明/羽化、原生右键菜单），**语音采集仅 Windows**。
- 语音识别与合成使用云端服务：需要联网，音频会发送给你配置的服务商；本版不内置本地识别/合成。
- 录音固定使用系统默认输入设备，默认 60 秒、上限 4 分钟；不支持唤醒词与自动断句。
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。
- Go 级进程内插件尚未开放；扩展能力目前走 MCP。
- 没有「工作区」概念：文件工具使用绝对路径或会话附件，不绑定当前目录。

## 校验

```text
aquarius.exe -version
Aquarius v0.1.0 (windows/amd64, go1.27.2)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。`SHA256SUMS.txt` 在构建机上生成：

```powershell
"$((Get-FileHash aquarius.exe -Algorithm SHA256).Hash.ToLower())  aquarius.exe" |
    Set-Content SHA256SUMS.txt -Encoding ascii
```
