# Aquarius v0.2.0
<!-- docs-sync: 2026-10-26 @ 15fa9a9 -->

第二个公开版本。这一版没有大改界面，主要做两件事：**把语音接成可替换的**，以及**把内部结构收口、压掉多窗时的内存**。
数据格式未变，替换 exe 即可升级。

## 这个版本新增

- **语音识别与合成变成「协议位」**。以前只有「对话接口」一条路，现在识别与合成各自可以选接法，设置窗
  「语音」页直接选：

  | 识别 | 合成 |
  |---|---|
  | 对话接口（默认，走模型那一套） | 对话接口（默认） |
  | **本地 whisper**——在本机识别，录音不出机器 | **VITS**（vits-simple-api 那类服务的 `/voice/vits`） |
  | **OpenAI 转写**——`/audio/transcriptions` | **GPT-SoVITS**（它的 `/tts`） |
  | **FunASR 原生**——FunASR 自带服务的 `/recognition` | |

  本地 whisper 把 whisper.cpp 编译进二进制，**不需要 cgo、不需要另起服务、不联网**；模型文件要自己下载
  （设置页写了在哪取、取哪个，约 60MB），路径不存在时只在状态栏警告一句，不会拖住启动。
  它输出的繁体中文会自动转成简体。

- **语音页只显示当前接法用得上的字段**。选了本地 whisper 就只剩「模型文件」和「录音语种」，选 FunASR
  不再要求识别模型名，选 VITS / GPT-SoVITS 时对话接口专用的音色描述、风格标签自动收起。被隐藏的字段
  不会丢值，来回换接法不会把之前填的内容清空。
- **固定选项改成弹层选择器**。设置窗里原来「点一下跳到下一个值」的字段（协议、语种、主题、采样档位等）
  改为点开一个居中面板，所有选项一次列全、当前值有标记，点一下就写上。面板会遮住整窗并接管键盘，
  按 Esc 或随便打字都不会漏到后面的编辑器。
- **网页搜索与语音可以各自配地址和密钥**。以前只能借「模型服务」里某一条的，现在这两路能单独填，
  留空仍回落到所选服务。
- **消息右键的编辑方式写了各自会发生什么**：「编辑」「编辑并转移历史」「编辑并复制历史」三项在浮层里
  直接说明后果，不用先记住区别再选。
- **内存**：多窗场景下 Go 存活堆从约 502MB 降到约 282MB。做法是同一种中文字体不再每个窗口各解析一遍
  （解析结果只读，重复解析纯属浪费）；同时把垃圾回收水位收紧到「存活的一倍半」，并加了一道防跑飞的上限。
  空闲时的工作集与上一版相当——那部分主要是渲染缓冲和字体本身，省不掉。

## 修掉的问题

- **密钥名越写越长、可能互相覆盖**：给同一个 provider 配第二把密钥时，名字会在已有引用后面不断叠后缀，
  留下一堆没人指向的旧条目；provider 名含中文时更会被压成同一个占位名，导致两条共用一个槽位、
  前一条开始用错密钥。现在所有写入路径共用一条规则：已经有引用就沿用，否则从 provider 名派生一个可读名字。
  网页搜索页也不再往 config 里写明文密钥，与模型服务页一致。
- **pptx 不再被当成「可转文本」**：它一直没有解析器，选中只会变成一个读不出内容的二进制占位。可选列表
  现在与真正的解析器一致（pdf / docx / xlsx / html 与文本文件）；pptx、rtf、旧版 Office 文档仍可从
  「所有文件」、拖拽或附件按钮加进来，行为与以前相同。
- **高级页的配置编辑器会撑满窗口**：以前固定 220dp，窗口拉高下面一大片空白、压矮又贴边。现在这类
  「只有一块正文」的页面会让正文吃掉剩余高度。
- **`/help` 没出现在命令清单与补全浮层里**：两边各自手写一份清单，漏了一个分支就悄悄不一致。现在清单
  从命令分支反推核对，少一条、多一条都会失败。
- **插入摘要后版本组被打散**：摘要衬垫是透明的，分组键应看最近的非衬垫祖先；以前会被切断成两组。
- **改人格时不强制转移历史**：人格是首节点快照，改而不转移会让后续对话挂在旧人格下，现在会拦下并说明。
- **摘要目标已被覆盖时仍允许插入**：现在会拒绝并说明已有摘要覆盖了这段。
- **删除子树时没说清版本链的连带后果**：删除确认句现在写明「另有 N 个新版本会一并失去溯源记录」。

## 安装

1. 下载 `aquarius.exe`（Windows x64），放到任意目录运行；
2. 首次运行会生成配置指针与模板，先打开**配置引导窗**：填 provider 名、接口地址、密钥与模型名；
3. 也可以手动编辑 `%USERPROFILE%\.aquarius\profiles\default\config.json`，或在设置窗「模型服务」页编辑；
4. 保存后重启即可对话；`/help` 查看全部命令。

**升级**：配置与会话都在 `~/.aquarius/`，本版磁盘格式未变，替换 exe 即可，不需要迁移。
改动配置前建议备份该目录（也可在应用内用 profile 隔离试验）。

**卸载**：删除 exe 与 `~/.aquarius/` 目录。

## 已知限制

- Windows 为完整形态；Linux/macOS 可构建运行，但 GUI 为降级形态（无托盘、全局热键、
  半透明/羽化、原生右键菜单），**语音采集仅 Windows**。
- 本地 whisper 需要自备 ggml 模型文件，不随二进制分发；云端识别与合成需要联网，音频会发送给你配置的
  服务商，除非识别方式选了「本地 whisper」。
- 录音固定使用系统默认输入设备，默认 60 秒、上限 4 分钟；不支持唤醒词与自动断句。
- 不提供自动更新；可执行文件未做代码签名，Windows SmartScreen 可能提示「未知发布者」。
- Go 级进程内插件尚未开放；扩展能力目前走 MCP 与技能。
- 没有「工作区」概念：文件工具使用绝对路径或会话附件，不绑定当前目录。
- 字体字距有一处缺陷：`T` 之后相邻字母会少一点间距，根因在上游渲染库，本版仍未修。

## 校验

```text
aquarius.exe -version
Aquarius v0.2.0 (windows/amd64, go1.27.3)
```

发布页同时附 `SHA256SUMS.txt`，下载后在 PowerShell 里比对：

```powershell
certutil -hashfile aquarius.exe SHA256   # 下载后算哈希
Get-Content SHA256SUMS.txt               # 与发布页给出的哈希对照
```

两边的哈希一致即可。`SHA256SUMS.txt` 在构建机上生成：

```powershell
"$((Get-FileHash aquarius.exe -Algorithm SHA256).Hash.ToLower())  aquarius.exe" |
    Set-Content SHA256SUMS.txt -Encoding ascii
```
