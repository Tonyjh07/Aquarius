## 1. 它是什么

Aquarius 是一个常驻桌面的 AI 助手。它不是一个网页，也不用打开浏览器：平时缩成一颗小球
浮在屏幕角落，按一下快捷键就展开成一条输入栏，打完字按回车，回答就在上方铺开。

它能做的事，大致这几类：

- **聊天**：问问题、写东西、翻译、改稿、解释一段看不懂的内容。
- **看东西**：点回形针、把文件拖到窗口上、或截图后按 Ctrl+V，把图片、PDF、Word、Excel、
  网页文件交给它，它读过再回答。
- **看屏幕**：让它「看看我现在这个窗口」，它会截屏后回答（截之前会先问你）。
- **动手**：读写文件、执行命令、跑后台任务——这些动作默认都要你点头才做。
- **记事**：把长期有用的信息写进记忆文件，下次对话它还记得。
- **联网**：让它搜网页、读某个网页的正文（用哪个搜索服务、抓取走本机还是走服务商，
  都可以在设置窗「联网」页里排）。
- **说话**：按麦克风键说一段，转成文字填进输入框；也可以让它把回答念出来。

它**不是**：不是全知全能的搜索引擎，回答可能出错；也不是云服务，你的对话默认只存在自己电脑上
（发出去的内容只到你配置的那家模型服务）。

## 2. 安装与第一次启动

### 2.1 放好程序

Aquarius 是**一个 exe 文件**，不需要安装程序。建议这样放：

1. 新建一个固定目录，例如 `D:\Apps\Aquarius\`；
2. 把 `aquarius.exe` 放进去；
3. 以后都从这个文件启动（可以右键「发送到 → 桌面快捷方式」）。

不要放在「下载」文件夹里随手双击——清理下载目录时容易连程序一起删掉。

### 2.2 第一次打开

双击后，屏幕上会出现一颗小球，同时弹出**欢迎窗**，分三步：

**第一步：接入模型**

| 你会看到 | 该填什么 |
|---|---|
| Provider | 一个自己起的名字，比如 `openai`、`mimo`。只是标签，随便起 |
| 接口地址 | 服务商给你的地址，通常以 `/v1` 结尾，例如 `https://api.openai.com/v1` |
| API 密钥 | 服务商给你的那串密码。填进去会被存进本机加密库，之后不再显示 |
| 模型名 | 要用的模型名字，例如 `gpt-4o`。逗号可以写多个，第一个是默认 |

填完可以点「测试连通」先试一下——绿点表示通了，红字会写清失败原因（地址错、密钥错、网络不通）。
「获取模型」会向服务端要一份可用模型清单，点候选名字即可替换。

**第二步：教程**——把基本操作、右键菜单、常用命令列一遍，扫一眼就行。

**第三步：完成**——显示将要保存的内容，点「保存」开始使用。密钥只显示形态（例如「已存入本机
加密库」），不会回显明文。

> 以后想再看这个向导：设置窗 →「常规」→「欢迎引导」→「打开」。
>
> 第一次启动会在 `C:\Users\<你的用户名>\.aquarius\` 下建好数据目录和一份配置模板。

### 2.3 如果双击没反应

先看**托盘**（屏幕右下角，时钟旁边的小图标区，可能要点开「^」）。程序默认只留一颗悬浮球和
一个托盘图标，**不占任务栏**，所以「没反应」经常只是窗口收起来了：

- 按 `Alt+A`（默认呼出键）；
- 或点托盘图标 →「显示 / 隐藏输入窗」。

如果托盘里也没有图标，多半是启动就报错了。这时**从终端启动**才能看到原因：

```powershell
cd D:\Apps\Aquarius
.\aquarius.exe
```

窗口会显示具体报错（密钥取不到、配置写错、数据目录没权限等）。按提示改，或看
[第 14 节](#14-遇到问题怎么办)。

## 3. 认识主窗口

### 3.1 悬浮球

平时它是一颗小球，浮在屏幕角落：

- **单击**：展开 / 收起输入栏；
- **按住拖动**：把它挪到别处；松手时贴到屏幕边缘会自动贴齐；
- **收起后停在左/右边缘**：球会滑出屏幕、只留一条窄边，鼠标移到窄边上（或按快捷键）就回来；
  上下边缘只贴齐，不会藏起来；
- **悬停**：弹出一张小卡，写着当前配置档、会话标题、模型、上下文占用和累计用量；
- **右键**：菜单（见下）。

球默认**置顶**，不会被别的窗口盖住；不需要置顶时在右键菜单里取消勾选。

### 3.2 球的右键菜单

| 菜单项 | 作用 |
|---|---|
| 新对话 | 开一个空白会话，旧会话不会丢 |
| 权限 → | 二级菜单，四档权限，当前档打勾 |
| 无人值守 | 勾选 = 越界操作直接拒绝、不再停下来问（见 11.4） |
| 消息历史 | 打开会话历史窗（左栏会话列表 + 右边关系图） |
| 设置 | 打开设置窗（十个页面） |
| 置顶 | 勾选 = 始终显示在最前面 |
| 隐藏 | 收起窗口（程序继续在后台） |
| 退出 | 真正结束程序 |

### 3.3 托盘图标

右键托盘图标：显示 / 隐藏输入窗、窗口置顶、无人值守、设置、会话历史、退出。

**关掉窗口不等于退出程序**：点窗口的关闭按钮只是收起，球和托盘图标还在。要彻底退出，
用菜单里的「退出」。

### 3.4 输入栏

展开后是一条胶囊形状的输入栏，从左到右三块：

1. **回形针**：选文件随消息发出去（见第 6 节，可一次选多个）。选好后会变成带文件名的标签；
   展开态每个文件一个标签，点标签本身 = 去掉那个文件。也可以直接把文件拖到窗口上，
   或者截图后按 Ctrl+V 贴进来（图片标签会带缩略图）；
2. **输入区**：打字。占位提示是 `Ask anything or type a command...`。
3. **右侧圆钮**，三种状态：
   - 输入框**有字**：向上箭头 = **发送**；
   - **正在生成**回答：方块 = **停止**（点一下立刻中断，已生成的部分保留）；
   - 输入框**空着**且配好了语音识别：麦克风 = **语音输入**（见第 7 节）。

输入栏右侧还有一个小小的「展开」槽（四角括号图标）：点一下把单行输入栏变成多行编辑区，
适合写长提示；再点收回。发送后自动收回。

单行状态下按 `Shift+Enter` 换行会被压成空格（「所见即所发」：单行框里换不了行）；要分段
写就先点展开。编辑一条本来就有多行的旧消息时，输入栏会自动展开。

### 3.5 状态行

生成回答时，输入栏下方会出现一行小字，例如「思考中 · gpt-4o · strict」或「生成中 · …」。
它告诉你现在在干什么、用的是哪个模型、当前权限档。没有在生成时这行是空的（开着无人
值守除外，见下）。

打开**无人值守**后，这行会一直挂着「无人值守」标记，提醒你现在越界的操作会被直接拒绝
（见 11.4）。

编辑旧消息时，这一行会变成「编辑中 · Enter 提交 / Esc 取消」。

### 3.6 消息区

回答在上方铺开，用户消息靠右、助手消息靠左：

- **思考过程**：模型「想」的时候正文会实时铺开；回答定稿后收成一行「▸ 已思考 N 秒」，
  点这一行展开、再点收起。收起只是不显示，内容仍在会话里。
- **工具调用**：模型调用工具时会显示一条小条（例如「读取文件 …」），点开能看到参数和结果。
  需要你批准时，输入栏会变成「原因输入框 + 三个圆钮」（见第 11 节），小条上也会写出要批准什么；
  开了无人值守则不问你，越界调用当场被拒（见 11.4）。
- **分支条**：同一条消息有多个版本时，旁边会出现「◀ 1/2 ▶」这样的小条，点箭头切换版本。
- **选择文字**：按住鼠标拖选，`Ctrl+C` 复制。整条复制用右键菜单「复制」更省事。

## 4. 第一次对话

展开输入栏，直接打字，按 `Enter`：

```
帮我把这段话改得更客气一点：这个方案不行，重做。
```

几秒后回答会一段段出现。想中途叫停就点输入栏右侧的方块按钮（生成中它一直显示）。

**生成中也能继续打字**：按 `Enter` 提交，这条会排队，等当前回答结束再发出去，不用干等。
排队中的消息会立刻显示在对话里，轮到你时自动处理。

几条实用习惯：

- **一次问一件事**。把背景、要求、期望的输出格式写清楚，比反复追问省事。
- **让它先问**。不确定需求时可以说「先别写，问我三个问题」。
- **不满意就重来**，不用重打：在回答上右键 →「重新生成」。
- **想改哪句就改哪句**：在消息上右键 →「编辑」（见第 8 节）。

第一次用建议先试这三句，熟悉手感：

1. 「用三句话解释一下这个程序能干什么。」
2. 「帮我把下面这段会议记录整理成待办清单：……」
3. 「我桌面上有个 PDF，帮我总结要点。」（点回形针选文件）

## 5. 日常聊天的手势与快捷键

| 操作 | 怎么做 |
|---|---|
| 发送 | `Enter`，或点右侧向上箭头 |
| 换行（不发送） | 先点展开切成多行编辑区，再用 `Shift+Enter`（单行框里换行会变成空格） |
| 停止生成 | 点右侧方块 |
| 呼出 / 收起输入栏 | `Alt+A`（可在设置里改；注册失败时自动改用 `Ctrl+Alt+A`） |
| 收起窗口（只剩球） | 点球，或点窗口关闭按钮 |
| 复制选中的文字 | 拖选后 `Ctrl+C` |
| 关掉命令补全浮层 | `Esc` |
| 取消正在编辑的消息 | `Esc`（编辑框清空，回到普通输入） |
| 展开 / 收起多行输入 | 点输入栏右侧的四角括号图标（展开时按 `Esc` 也能收回） |

> 输入框**没有**「翻历史消息」的快捷键（`↑` `↓` 只在命令补全浮层里用来选项）。

**斜杠命令**：输入框里打 `/` 会弹出补全列表，`↑` `↓` 选、`Enter` 确认、`Esc` 关掉。
常用的几个（完整清单见[参考手册](usage.md)）：

| 命令 | 作用 |
|---|---|
| `/new [标题]` | 新建会话 |
| `/list` | 列出所有会话 |
| `/switch <编号前缀>` | 切到某个旧会话 |
| `/title [新标题]` | 看 / 改当前会话标题 |
| `/model [名字]` | 看可用模型 / 换模型（立即生效） |
| `/permission [档位]` | 看 / 换权限档 |
| `/unattended [on\|off]` | 无人值守：越界的操作一律当场拒绝并说明，不弹确认打扰你（权限档不变） |
| `/compact` | 把较早的往来压成一条摘要（省上下文） |
| `/usage` | 看这次会话用了多少 |
| `/jobs` | 后台任务列表 / 日志 / 终止 |
| `/mic` | 录一段话，转成文字直接发送 |
| `/memory` | 用系统编辑器打开记忆文件 |
| `/help` | 命令清单 |
| `/quit` | 退出程序 |

> 记不住命令没关系：绝大多数操作在右键菜单和设置窗里都有对应入口。

## 6. 让它看文件、看图片、看屏幕

### 6.1 附件

有三种方式把文件交给它：

- 点输入栏左侧的**回形针**选文件——可以一次选多个（文件框里按住 Ctrl 或 Shift 多选）；
- 把文件**直接拖到窗口上**松手——拖几个都行；
- 截图或复制了图片之后，在输入栏里按 **Ctrl+V** 直接贴进来。

贴进来的图片会在标签最左边显示一张小缩略图，拖进来的图片文件也一样——贴的是哪张一眼就能
认出来。剪贴板里是文字时，Ctrl+V 还是普通的文字粘贴，不会被抢走。

- 选好后输入栏里会出现标签，写着文件名；标签在，说明这些文件会**跟着下一条消息一起发出去**；
- 展开输入栏（点右侧的四角括号）能看到每个文件一个标签，点某个标签 = 去掉那一个文件；
- 收起状态下只显示一个汇总标签（`3 个文件`），点它 = 全部清掉；
- 一条消息最多 **8 个**文件；同一个文件不会被重复添加；
- 图片单张不超过 **20 MB**，超了会明确告诉你多大、上限多少，不会悄悄丢掉；
- 拖进来的如果是文件夹，会提示「是文件夹，请拖入或选择具体文件」——这里只收文件；
- 发出去以后标签自动清掉；其中一个文件读不了也不影响别的，它会在提示里说清哪个被跳过、
  为什么。

> 贴图与拖拽在 Windows 上可用；其他系统仍以回形针选文件为准。

几处衔接要知道：

- 等你在确认框里点头的时候，附件位整行换成了确认按钮，这时点不到回形针；
- **编辑一条旧消息时也能改附件**：进编辑态后输入栏里会列出这条消息已有的附件，点一下某个
  标签 = 标记为移除（标签变暗并划掉，再点一下恢复）；这时用回形针选文件、`Ctrl+V` 贴图或
  拖文件进来，都是给这次修订**新增**附件。只改附件、不改文字也行（文字留空直接回车）。
  改完至少得留下一段文字或一个附件——全删光会被拒绝。

**能读的格式**：

| 类型 | 处理方式 |
|---|---|
| 图片（png / jpg / gif / webp 等） | 直接把图给模型看（模型得支持看图，否则会提示） |
| PDF | 抽出文字 |
| Word（.docx） | 抽出文字 |
| Excel（.xlsx / .xlsm） | 抽出表格文字 |
| HTML / 网页文件 | 抽出文字 |
| 纯文本、Markdown、JSON、代码文件 | 直接读 |

抽出来的文字有长度上限：纯文本类约 32 KB，PDF / Word / Excel / 网页类约 64 KB（中文大约
一两万字）。超出部分不会写进对话，但**模型可以自己再翻**（它有个读文件的工具），你也可以
直接说「继续读后面」。

> 提示：图片里的小字、模糊截图，模型可能看错。重要数字建议再用文字确认一遍。

### 6.2 看屏幕

直接说「看看我现在这个窗口」「屏幕上这个报错是什么意思」，模型会：

1. 先列出可抓取的窗口；
2. 请求截屏——这时会弹确认（截图属于要点头的动作）；
3. 截好后回答。

几点限制：

- 只支持 **Windows**；
- 被别的窗口挡住也能抓到（抓的是那个窗口自己画的内容）；最小化的窗口也能抓，取的是系统合成器
  留着的那一帧，所以图里会连标题栏一起带上，窗口本身不会被还原、也不会跳到前台；
- 抓不到时会明确告诉你原因，不会假装看到了；
- 当前模型不支持看图时，会直接提示，不会硬发。

### 6.3 记忆

它有两份记忆：一份**全局**（所有会话共用），一份**跟着单个会话走**。

- 让模型「记住：我习惯用中文回答」，它会写进记忆；
- 想看 / 手改：输入 `/memory`，会用系统默认编辑器打开记忆文件（Markdown，随便改）；
- 记忆只在本机，不会自动同步。

## 7. 说话与朗读

语音功能要**先配置**，没配置时输入栏右侧永远是发送键，不会出现麦克风。这里说的「配置」
指的是**语音识别**——录完要转成文字，缺的是识别服务（合成只负责把回答念出来）。

### 7.1 配置一次

设置窗 →「语音」页，上下两段：

**语音识别（说话转文字）**

| 字段 | 说明 |
|---|---|
| 识别服务 | 从「模型服务」页里已有的条目中选一个；留空 = 关闭语音输入 |
| 识别模型 | 服务商提供的识别模型名，例如 `mimo-v2.5-asr` |
| 录音语种 | 自动识别 / 中文 / 英文。只影响识别，不改界面语言 |

**语音合成（文字转语音）**

| 字段 | 说明 |
|---|---|
| 合成服务 | 同上，留空 = 关闭朗读 |
| 合成模型 | 例如 `mimo-v2.5-tts`；`-voicedesign` 是按描述设计音色，`-voiceclone` 是克隆音色 |
| 音色 | 预置音色名；用克隆模型时填**样本音频文件的完整路径** |
| 音色描述 | 用「音色设计」模型时必填，例如「温柔的女声，语速偏慢」 |
| 风格指令 | 一句话描述语气，例如「语速稍快，语气轻松」 |
| 风格标签 | 几个词，会拼在正文前，例如「温柔 语速稍快」 |
| 试听 | 点「播放示例」，用当前填的内容合成一句；合成中按钮变「合成中…」 |

保存后：**换服务、换模型、换录音语种都要重启程序才生效**（这三项在启动时装配）；
改音色、描述、风格对**之后**的朗读立即生效，不用重启。

### 7.2 语音输入

1. 确保输入框是**空的**（有字时右钮是发送键）；
2. 点麦克风，开始录音（圆钮变成停止方块）；
3. 说完再点一下方块结束；
4. 等一两秒，识别结果**填进输入框**——不会自动发送，你可以先改错字，再按 `Enter`。

录音默认最长 60 秒，最多 4 分钟；到时间会自动停并开始识别。录音只在 **Windows** 可用。

想一句话直达（不经过输入框）就用 `/mic`：录完、转写、直接作为你的消息发出去。

> 音频会上传到「识别服务」指定的那家服务商。介意隐私的话，把识别服务留空即可关闭。

### 7.3 朗读回答

设置窗 →「常规」→「输出」→ 勾上「语音播报（回答完成后自动播放）」。

- 每条回答完成后自动念；
- **只念正文**，不念思考过程和工具调用；
- 长回答会整段合成，可能等一两秒才出声；
- 同一时刻只念一条：新回答开始播报时，上一条会被打断（不会两条声音叠在一起）；
- 生成过程中点停止键（方块）会顺带把正在念的声音静音；
- 想彻底关掉：取消勾选并保存（**下次启动**才不再装配播报；当次想立刻静音就退出程序）。

> 勾了却一直没声音，先确认「语音」页的合成服务和合成模型都填了，并且已经重启过。

### 7.4 语音常见毛病

| 现象 | 多半是 |
|---|---|
| 右侧没有麦克风 | 语音页里「识别服务」留空，或识别模型没填（合成配了也不算——录完要转写） |
| 点了没反应 / 立刻失败 | 麦克风被别的程序占用，或系统里禁用了麦克风权限 |
| 录到了但没文字 | 识别模型名写错、服务地址不对、密钥过期 |
| 有文字但全是错的 | 语种选错（中文录音选了英文）；或说话离麦克风太远 |
| 勾了朗读却没声音 | 「合成服务」或「合成模型」没配；或系统音量 / 输出设备不对 |
| 试听报「语音合成未配置」 | 保存后**没重启**——换服务、换模型都要重启 |

## 8. 改一条消息会发生什么

这是它和普通聊天软件最不一样的地方：**旧消息永远不被改写**。你「改」一条消息，实际上是
在它旁边长出一条新分支，原来的版本原样留着，随时能切回去。

在任意用户消息或回答上**右键**，菜单如下：

| 菜单项 | 会发生什么 | 什么时候用 |
|---|---|---|
| 编辑 | 改这一条，**从这里重新开始**；后面的对话留在旧分支上，新分支从这条之后重新生成 | 想问一个略微不同的问题，看看另一个答案 |
| 编辑并转移历史 | 改这一条，**把后面的对话接到新分支上**（后续内容原样保留，不重新生成） | 只是措辞写错了，不想让模型重答后面 |
| 编辑并复制历史 | 改这一条，并把后面的对话**复制一份**到新分支；新旧两条互不影响 | 想留一份原样，再在副本上试验 |
| 重新生成 | 不改文字，直接让它再答一遍（在上一条的基础上分叉） | 答案不满意 |
| 复制 | 整条复制到剪贴板 | 拿去别处用 |
| 引用 | 把这条内容作为引用前缀放进输入框 | 针对某段话追问 |
| 查看原文 | 弹窗显示未经排版的原始文字 | 排版看着怪、想确认原文 |
| 生成响应 | 以这条消息为起点，让它继续往下说一条 | 中途停了、或想从旧节点接着聊 |

**编辑怎么操作**：

1. 右键 →「编辑」（或「编辑并转移历史」/「编辑并复制历史」）；
2. 输入框会预填原文，状态行显示「编辑中…」；
3. 改完按 `Enter` 提交；按 `Esc` 取消；
4. 提交后视图跳到新分支。旧分支没消失——旁边会出现「◀ 1/2 ▶」的小条，点箭头就能切回去。

> 一条经验：**只是想改错别字**，用「编辑并转移历史」；**想换个问法看新答案**，用「编辑」；
> **想保留原样做对照**，用「编辑并复制历史」。

思考块和工具小条也有右键菜单，但只有「复制」和「查看原文」——它们不是你说的话，不能改。

## 9. 找回旧对话与看清分支

### 9.1 打开历史窗

三种方式，效果一样：

- 球右键 →「消息历史」；
- 托盘右键 →「会话历史」；
- 或者直接用命令 `/list`、`/switch`。

### 9.2 左栏：会话列表

- 按最近使用排序，当前会话高亮；
- 每行显示标题、时间、消息条数；
- **「＋」**：新建一个会话；
- **「◀」**：把左栏收起来，把宽度让给右边的图；收起后点窄条顶部的「▶」再展开；
- **鼠标移到某一行**，行尾出现「✕」：删除这个会话（会二次确认；删的如果是当前会话，
  会自动切到另一个）。

### 9.3 右栏：关系图

这张图就是这棵「对话树」的样子。看三件事：

**形状 = 谁说的**

| 形状 | 含义 |
|---|---|
| □ 方块 | 你说的话 |
| ● 圆点 | 助手的回答 |
| ◇ 菱形 | 系统消息（例如摘要） |
| ◯ 空心圆 | 会话的根 |
| △ 三角 | 注入的上下文（系统或任务塞进去的旁注） |

**颜色深浅 = 离根多远**。越往下越深，用来快速看出主线在哪。

**分叉 = 版本**。同一个位置有多条线分开，就是同一句话的不同版本。

**操作**：

- 单击节点：在窗内弹出一张卡片，可以看内容、也可以改（见下）；
- 右键节点：编辑类操作 + 「复制 ID」「插入摘要」「删除该节点及子树」「转到」；
- 滚轮：缩放；拖动空白处：平移；
- 状态栏：会话标题、共几条 / 当前显示几条；右侧一排小控件——「−」「＋」调一次画多少条、
  「缩放 100%」是当前缩放（只显示）、「装下整树」「回到初始态」「聚焦当前历史」
  「聚焦当前节点」各管一种取景；再下面是图例（形状与深浅）。

### 9.4 节点卡片（单击后）

卡片上方有「呈现 / 源码」两个页签：前者是排好版的样子，后者是原始文字；人格节点还多一个
「默认模板」页签（编辑以后新建会话用的人设模板，见 10.6）。

底部三种应用方式，和右键菜单里的三种编辑一一对应：

- **另起新分支**：改完从这里重新长一条；
- **转移历史**：改完把后面的历史接过来；
- **复制历史**：改完把后面的历史复制一份。

改完点「保存」。人格节点（系统提示词）只能选「转移历史」，这是故意的——新人格要接管后面
整段对话；如果改成「另起新分支」，你会看到「改一句人格，对话全没了」（旧历史都留在旧分支上）。

「插入摘要」是另一回事：在那个位置插一条摘要，作为新的「从这里往后才发给模型」的分界线，
用来省上下文。可以让模型总结以上历史，也可以自己写。

### 9.5 删除

- **删节点**：右键 →「删除该节点及子树」——它和它下面的所有内容一起消失，会先确认；
- **删会话**：左栏行尾「✕」——整个会话消失，会先确认。

删除是不可撤销的。重要的会话建议先备份（见第 13 节）。

## 10. 设置窗逐页导览

打开方式：球右键 →「设置」，或托盘右键 →「设置」。

左边是十个页面，右边是内容，底部固定一条「保存并应用」。**改完一定要点它**——不点等于没改。
保存后底部会给一句反馈，说明哪些改动立即生效、哪些要重启。

例外：「模型服务」页有自己的一颗「应用 provider 变更」（那张页的改动走它），「密钥库」页
点「存入密钥库」即入库，「工具与 MCP」页的开关点了就生效——这三处不用等底部的保存。

### 10.1 常规

| 区块 | 能改什么 |
|---|---|
| Profile | 「配置档」——一套独立的配置 + 会话 + 记忆 + 附件。可以新建、复制当前、切换。**切换要重启** |
| 欢迎引导 | 重新打开第一次的向导（模型接入 + 操作教程） |
| 权限 | 四档权限与「无人值守」开关，见第 11 节 |
| 外观与呼出 | 全局快捷键、主题（跟随系统 / 浅色 / 深色）、元素缩放、字号、窗口尺寸 |
| 输出 | 桌面通知（回答完成时）、语音播报（回答完成后自动播放） |

> 快捷键填 `Alt+A` 这种格式；留空 = 用默认值。改完立即生效，不用重启。
> 如果填的组合被别的程序占了，程序会退回 `Ctrl+Alt+A`。

### 10.2 模型

| 字段 | 说明 |
|---|---|
| 当前模型名 | 现在用哪个模型。改完保存会**立即切换**，不用重启 |
| 原生思考 | 开 / 关。关掉后模型不再输出思考过程（有些模型不支持，关了也没损失） |
| 推理档位 | 未设 / minimal / low / medium / high。越高想得越久、通常越贵 |
| 降级链 | 主模型失败时依次尝试的备用模型。可以加多条、上移下移、删除 |

「降级链」的白话版：**主力模型连不上或报错时，自动换下一个试试**，免得你干等。
链上的模型最好都支持看图——否则图片消息轮到它们时会失败。降级链的改动**保存后重启**才生效。

### 10.3 模型服务

这里管理「从哪家服务商取模型」。每一张卡片是一个服务（点标题行展开 / 收起）：

| 字段 | 说明 |
|---|---|
| 名称 | 内部标识，别处按这个名字引用 |
| 协议 | 三种：chat（最常见，`/chat/completions`）、responses（OpenAI Responses）、anthropic（Anthropic Messages）。选错了连不通 |
| 接口地址 | 服务商给的地址，通常以 `/v1` 结尾 |
| 密钥 | 密钥池：可以放多把，一把被限流就换下一把 |
| 不认参数 | 有些服务端不认某些参数，填在这里会被自动剔除，避免报错 |
| 模型列表 | 每个模型一行：启用勾选、名字、上下文窗口；下面三个能力勾选（工具 / 思考 / 图片） |
| Tokenizer | 可选：本地 `tokenizer.json` 的路径，用来精确数 token；留空 = 估算 |

页面里还有「测试连通」「获取模型」「探测能力」——都是**发真实请求**，会消耗一点点额度。
**这一页的改动要点「应用 provider 变更」，然后重启**。

### 10.4 密钥库

存各种密钥的地方。列表只显示名字和末四位，值永远不回显。

- **新增 / 覆盖**：填名字和值，点「存入密钥库」即入库；
- **导入旧密钥**：把以前直接写在配置文件里的明文、或只存在环境变量里的值，一键收进库；
- **删除**：行内二次确认。

密钥存在本机加密文件里（Windows 上绑当前用户账户）。**把文件拷到另一台电脑是解不开的**
（这是故意的），换机时请重新填；同一台电脑换个 Windows 账户也解不开。

### 10.5 对话

调「用多少」的几个上限，一般不用动：

| 字段 | 说明 |
|---|---|
| 最大轮数 | 一次提问里，模型最多能连续调用几轮工具 |
| 上下文上限 | 一次能带多少内容（字数预算）。越大越贵、越慢 |
| 压缩阈值 | 用到多少比例时自动把旧内容压成摘要，默认 0.7（七成） |
| 工具输出上限 | 单个工具的输出最多保留多少字，超出截断 |
| 工具超时 | 单个工具最多跑多久（秒） |

### 10.6 系统提示词

这里是它的「人设」：一段长期生效的说明，决定它怎么说话、守什么规矩。

- **人格模块**：把长提示词拆成小块（例如「身份」「语气」「禁忌」），可以增删改、拖动排序；
- **人格引用**：决定哪些模块按什么顺序拼起来；
- **内置模块**：只读，可以引用，不能改；
- **组合预览**：看看最终拼出来是什么样。

改完保存，**只对之后新建的会话生效，而且要重启程序才应用**（老会话保留它自己那份人设，
不会被偷偷改掉）。

会话首节点上那个「默认模板」页签改的是**以后新建会话**用的人设模板，改完点「保存模板」；
同页的「应用到本会话」则是把当前编辑结果用在这个会话的人格节点上（等同改人格节点，
会走「转移历史」）。

### 10.7 工具与 MCP

- **内置工具**：一排开关。关掉的工具模型就看不见，也就不会调用。**即时生效**。
- **MCP 与插件**：外部扩展工具。列表里能看到状态，可以启用 / 停用、授权、看调用日志。

第一次启用某个扩展时，它会申请能力（读文件、联网等），要你逐项同意。**不同意就不启动**。

### 10.8 联网

它联网做两件事：**搜索**（找网页）和**抓取**（把某个网页的正文读下来）。两件事各有自己的
提供商列表，**排在前面的先用，失败自动换下一家**。

| 区块 | 说明 |
|---|---|
| 搜索提供商 | 可加多条。`deepseek` 借「模型服务」里的某一家（省一把钥匙）；`brave` 要自己的订阅令牌 |
| 搜索条数 | 一次返回几条结果（1–20） |
| 抓取提供商 | `deepseek` 借模型服务；`local` 是**本机直接抓**，不需要钥匙，默认就开着 |
| 正文上限 | 单次抓回来的正文最多多少字（500–20000），超出截断 |
| 代理 / 浏览器标识 | 本机抓取走哪个代理、以什么身份请求（很多站点拒绝非浏览器身份） |
| 遵守 robots.txt | 默认开。站点的抓取规则说不行就不抓 |
| 允许内网地址 | 只给调试本机服务用，平时别开 |
| 超时 | 单次抓取最多等多少秒（1–600） |

每条提供商右边的 ↑ ↓ 调优先级、× 删掉。密钥框**永远空白**（值不会显示出来）——留空 =
沿用原来那把，想换就填新的；填 `secret:名字` 表示引用密钥库里的那把，直接填值则按明文存
（启动时会提醒你）。

把某一侧的列表清空 = 那件事不可用（比如不想要搜索，就把搜索提供商全删掉）。

### 10.9 语音

见第 7 节，这里不重复。

### 10.10 高级

直接编辑配置文件的原文（JSON）。适合改那些界面上没有的项。

- 改坏了不会立刻生效——保存时会校验，格式错会拒绝并保留原文件；
- 保存后部分改动要重启；
- 不确定就先备份这个文件（见第 13 节）。

## 11. 权限与确认

### 11.1 它为什么要问我

模型会「动手」：写文件、删文件、执行命令、截屏、跑后台任务。这些动作有风险，所以默认
**每次都要你点头**。

要点头时，输入栏会变样：中间显示一句问话（例如「允许执行 term_exec？参数: {...}」），
左边是**原因框**，右边三个圆钮：

| 圆钮 | 作用 |
|---|---|
| ✗ 叉 | **拒绝**：这一次不做。原因框里写的字（可留空）会告诉模型为什么 |
| ✓ 勾 | **允许**：这一次放行 |
| 🔑 钥匙 | **提升权限**：把权限档升一级，并放行这一次。以后同类动作就不再问了——**谨慎使用** |

- 在原因框里按 `Enter` = **拒绝**（连同原因），不会误放行；
- 点别处、按 `Esc` 都不会放行——只有点这三个圆钮才算数；
- 悬停在圆钮上会显示它的名字。

### 11.2 四档权限

| 档位 | 写文件 | 执行命令 |
|---|---|---|
| `read-only` | 哪都不能写（每次问） | 每次问 |
| `strict`（默认） | 只有沙盒里免问，别处每次问 | 每次问 |
| `permissive` | 哪都能写，不问 | 每次问 |
| `full-access` | 哪都能写，不问 | 不问，直接做 |

**沙盒**是数据目录下的 `sandbox` 文件夹，专门给它放临时产物。想让它随便写东西又不放心，
就让它把文件写到那里（`strict` 下只有这个文件夹免问）。

**读**文件在四档里都不用问——它本来就能读你硬盘上的文件。介意的话，别把敏感文件放在
它会翻的地方，或者在设置里关掉对应的工具。

### 11.3 怎么选

- 日常用 **strict**：能干活，但出不了大圈；
- 让它整理下载目录、批量改名：临时切 **permissive**；
- **full-access 只在你完全信任当前任务时用**，用完切回来。

切换方式：球右键 →「权限」，或设置窗 →「常规」→「权限等级」，或 `/permission permissive`。
**切换立即生效**，并会记住，下次启动沿用。

> 密钥、联网这类授权不跟权限档走——它们有单独的授权流程，不会因为升档就自动放开。

### 11.4 走开一会儿：无人值守

要它跑一件长任务、你又不打算守在屏幕前时，打开**无人值守**（球右键 / 托盘右键的
「无人值守」、设置窗 →「常规」→「权限」，或 `/unattended on`）：

- **权限档一个字都不改**——只是需要确认的操作不再弹窗问你，而是**当场拒绝**并告诉模型原因
  （没人能批准、别重试、在允许范围内继续、把待批的事列出来）。模型会改道，整轮不会卡住。
- 你自己亲手输入的命令（删会话这类二次确认）和插件授权**照常问你**——那时你就在键盘前。
- 模型想反问你的问题（提问工具）也会直接得到「用户不在」，不会停在那里等你两分钟。
- 开着的时候状态行一直显示「无人值守」，回来看到一串「已拒绝」时先看它，别当成故障。
- 它和启动参数 `-yes` 方向相反（那个是**自动放行**）。两者同时出现时 `-yes` 优先，
  启动会打一条警告说明本次没启用无人值守。

## 12. 后台任务

有些活要跑很久（下载、编译、批量处理）。模型可以用「后台任务」的方式启动，然后继续和你聊：

- 任务在独立进程里跑，**不随对话取消**（停止生成也停不掉它）；
- 输出写进日志文件，跑完会主动汇报结果（会以一条注入消息出现在对话里），不用你反复问；
- 输入 `/jobs` 可以看列表、看日志尾部、终止某个任务；
- 日志位置：数据目录下 `jobs\<任务编号>.log`。

想主动让它跑长任务，直接说「后台跑，跑完告诉我」即可。

## 13. 数据、备份与隐私

### 13.1 东西都存在哪

全部在：

```
C:\Users\<你的用户名>\.aquarius\
├── config.json                 记着「当前用哪个配置档」
└── profiles\
    └── default\                ← 一个配置档
        ├── config.json        主配置
        ├── sandbox\           给它写文件的沙盒
        ├── memories.md        全局记忆（可直接编辑）
        ├── conversations\     会话，一个会话一个 JSON 文件
        ├── attachments\       附件（图片、文档）
        ├── jobs\              后台任务日志
        ├── secrets.bin        密钥库（本机加密）
        ├── audit.log          调用审计日志
        └── gui_pos.json       窗口上次停在哪
```

会话记忆就在 `conversations\` 里，跟着会话走（`<编号>.memory.md`）。

想换位置，启动时加 `-data D:\某目录` 即可。

### 13.2 备份

最省事的办法：**退出程序，把整个 `.aquarius` 文件夹复制走**。只想备份一个配置档时，
复制 `profiles\<名字>` 就行——但根目录的 `config.json` 记着「当前用哪个档」，换机时
建议连它一起带上，否则启动后可能落到另一个档。

- 会话、记忆、附件、任务日志都在里面；
- `secrets.bin` 在别的电脑上解不开（预期行为），换机后重新填一次密钥即可；
- 只想备份聊天记录：复制 `conversations` 文件夹就够；
- 误删了某个会话：同目录下可能有 `<编号>.json.bak`（上一版），改名去掉 `.bak` 就能恢复。

### 13.3 换电脑

1. 退出程序；
2. 复制整个 `profiles\<名字>` 到新电脑同样的位置；
3. 把 `aquarius.exe` 也拷过去；
4. 启动，重新填一次密钥（设置窗 →「模型服务」，或「密钥库」）。

### 13.4 卸载

1. 菜单 →「退出」；
2. 删掉 `aquarius.exe`；
3. 想彻底清干净，再删 `C:\Users\<你的用户名>\.aquarius\`（**这会连所有会话和记忆一起删掉**）。

程序不写注册表、不装服务；快捷键和托盘图标只在运行时存在，进程退出就没了。删掉文件就是卸载。

### 13.5 哪些内容会离开本机

- **发给模型服务的内容**：你的消息、附件的文字或图片、被截的屏、要朗读的正文、录音的音频。
  只发给你在「模型服务」里配置的那一家（以及降级链上的备用家）。
- **不发的东西**：会话历史、记忆文件、密钥库、审计日志——这些只在本机。
- **密钥**：以请求头的形式发给对应的服务商，不写日志、不进会话文件。
- **桌面通知**：只在本机弹。

## 14. 遇到问题怎么办

### 14.1 启动相关

| 现象 | 怎么办 |
|---|---|
| 双击后什么都没有 | 看托盘和 `Alt+A`；都没有就从终端启动看报错 |
| 提示「配置不完整」 | 欢迎窗里把接口地址、密钥、模型名填全；或设置窗 →「模型服务」 |
| 提示密钥取不到 | 密钥过期或名字写错。设置窗 →「密钥库」重填 |
| 提示旧格式会话 | 按提示里点名的编号，删掉 `conversations\<编号>.json`（连同 `.bak`）再启动 |
| 启动就退出，终端有红字 | 按红字改；多半是配置项拼错、数据目录没有写权限，或模型服务连不上 |
| 换了配置档后像「失忆」 | 正常：每个配置档的会话和记忆是分开的 |

### 14.2 对话相关

| 现象 | 怎么办 |
|---|---|
| 一直「思考中」不动 | 网络不通或服务商在排队；点右侧方块停掉，再试一次 |
| 报 401 / 403 | 密钥错、过期、或没有该模型的权限 |
| 报 429 | 请求太频繁或额度用完；等一会儿，或在「模型服务」里加一把备用密钥 |
| 报「上下文超限」 | 用 `/compact` 压缩，或开新会话，或换窗口更大的模型 |
| 回答到一半断了 | 网络抖动；让它「接着上面继续」 |
| 图片发过去说看不了 | 当前模型不支持看图；换一个支持看图的模型，或把图里的文字打出来 |
| 从终端启动时中文是乱码 | 那是控制台编码问题，不影响界面；可以先执行 `chcp 65001` 再启动 |
| 界面文字突然变大变小 | 设置窗 →「常规」→ 元素缩放 / 字号 |

### 14.3 窗口相关

| 现象 | 怎么办 |
|---|---|
| 找不到窗口 | `Alt+A`；或托盘 →「显示 / 隐藏输入窗」 |
| 球不见了 | 托盘图标还在吗？在就点「显示」；不在就重新启动 |
| 球挡住东西 | 拖到屏幕左/右边缘并移开鼠标（收起态会滑成窄条），或右键取消「置顶」 |
| 快捷键按了没反应 | 被别的软件占用；设置窗换个组合，或程序已自动退到 `Ctrl+Alt+A` |
| 窗口跑到屏幕外 | 重新启动程序，它会按屏幕范围把位置拉回来 |
| 关不掉 | 关窗只是隐藏；要退出用菜单里的「退出」 |

### 14.4 语音与截图

见 7.4；截图失败通常是这个窗口由 GPU 直接绘制、系统合成器不给预览，或模型不支持看图。

### 14.5 想反馈问题

从终端启动程序，把红字连同以下信息一起提供，能省很多来回：

```powershell
.\aquarius.exe -version
```

会打印版本、平台和 Go 版本。再加上你刚才做了什么、期望什么、实际什么。

## 16. 名词小词典

| 界面上的词 | 白话解释 |
|---|---|
| 模型 | 背后真正在「思考」的那个 AI。不同模型能力、价格、速度不一样 |
| 模型服务 / Provider | 提供模型的商家和接入点。你要有它的地址和密钥才能用 |
| 密钥 / API 密钥 | 商家给你的一串密码，用来证明「是你」。别外传 |
| 上下文 | 这一次对话里，它能同时「看到」的内容总量。满了就要压缩或开新会话 |
| 压缩 / 摘要 | 把很早的往来浓缩成一段摘要，腾出空间。原文不会被删，还能翻回去 |
| 降级链 | 主力模型出问题时，自动改用的备用模型顺序 |
| 工具 | 模型可以调用的「手」：读文件、写文件、执行命令、截屏、跑后台任务 |
| MCP / 插件 | 外部扩展，给模型加新工具。启用时要授权 |
| 权限档 | 决定它哪些动作要问你、哪些可以直接做 |
| 沙盒 | 一个专门给它写文件的文件夹，写这里通常不用问 |
| Profile / 配置档 | 一整套独立的配置 + 会话 + 记忆。可以给工作、生活各建一个 |
| 分支 / 版本 | 同一句话的不同改法各成一条线，互不覆盖 |
| 节点 | 会话树里的一个点，就是一条消息 |
| 摘要节点 | 插在树里的「分界线」，它之前的旧内容不再发给模型 |
| 注入 | 系统或任务塞进对话的旁注，不算你说的话 |
| 后台任务 | 独立跑的长时间任务，不打断聊天，跑完自动汇报 |
| 试听 | 在语音页用当前音色合成一句话，先听听效果 |
