# Aquarius 稳定声明（docs/stability.md）
<!-- docs-sync: 2026-11-22 @ baf6609 -->

> 这一篇是 Aquarius 对外承诺的稳定面：数据兼容、支持平台与不承诺项。每版发布说明的
> 「已知限制」引用本篇，不各自另写一份。磁盘上的具体形状见
> [storage.md](storage.md)（权威处），本篇只写承诺级结论。

## 数据兼容承诺

- **向后兼容**：新版 Aquarius 能打开旧版本写下的会话、配置与附件，历史数据不需要导出重导。
- **向前不承诺**：用新版写过的数据，在旧版本上的行为没有保证——升级后不要用旧版打开同一份数据。
- **不做自动迁移**：早期格式的数据（如旧版单文件配置）在启动时明确报错、拒绝加载，原文件
  保留在原地不动。需要旧数据时按 [storage.md](storage.md) 的说明手动处理。
- **备份即拷贝**：数据全部是明文文件、无数据库、无锁文件，备份就是复制目录；升级前后备份方式不变。

## 支持的平台

| 平台 | 状态 | 说明 |
|---|---|---|
| Windows | 主要支持 | 发布二进制按 Windows 构建；悬浮球 GUI 与终端界面都以此为基准 |
| Linux | 支持（自行构建） | 构建与静态检查经 WSL 的 Linux 工具链验证；不发布 Linux 二进制 |
| macOS | 不承诺 | 未在测试范围，不保证可用 |

## 不承诺的事

- **自动更新**：更新靠手动下载并替换二进制，程序不自检新版本、不自动升级。
- **代码签名**：发布二进制不做签名；Windows SmartScreen 对未签名程序的提示属正常现象。
- **PTC（提示驱动工具调用）**：实验性能力，形态随版本调整，不承诺稳定。
- **模型辅助决策**：实验性能力（默认关、可开影子模式），阈值语义与配置键随版本调整，
  不承诺稳定；判定不放宽权限矩阵，矩阵本身的语义是稳定的。
- **上游字体缺陷**：个别字体在特定字号下的渲染问题源于字体文件本身，不在修复范围。
- **界面文案细节**：文案随版本打磨，脚本或测试不应依赖具体文案字符串。

## 维护

每版发布前复核本篇；承诺变化（新增不承诺项、平台升降级）在当版发布说明的行为变更里写明。
